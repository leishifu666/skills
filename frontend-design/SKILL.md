此技能引导创建具有特色、生产级的前端界面，避免通用的“AI 质感 (AI slop)”审美。实现真正的可用代码，并对审美细节和创意选择给予极大的关注。

## 设计思考

在编码之前，请理解上下文并致力于一个**大胆**的审美方向：
- **目标**：这个界面解决了什么问题？谁在使用它？
- **基调**：选择一个极端：极简主义、极繁主义、复古未来主义、有机/自然、奢华/精致、俏皮/玩具感、社论/杂志感、粗野主义、装饰艺术/几何、柔和/粉彩色、工业/实用等。
- **差异化**：是什么让它**令人难忘**？

**核心提示**：选择一个明确的概念方向并精准执行。大胆的极繁主义和精致的极简主义都行 - 关键在于**意图**。

## 前端审美准则

关注点：
- **排版 (Typography)**：选择漂亮、独特且有趣的字体。**避免使用 Arial 和 Inter 等通用字体**；转而选择能提升前端审美的独特字体。
- **色彩与主题**：致力于一个连贯的审美。使用 CSS 变量保持一致性。
- **动效 (Motion)**：使用过渡效果和微交互。优先使用原生的 CSS 方案。关注高光时刻：一个编排良好的整页加载（使用 staggered reveals）比零散的微交互更能带来惊喜。
- **空间构图**：意想不到的布局。不对称、重叠、对角线流、打破网格的元素。
- **背景与视觉细节**：营造氛围和深度，而不是默认使用纯色。添加符合整体审美的背景效果，如渐变网格、噪点纹理、几何图案、图层透明度、颗粒叠加等。

**严禁使用**：通用的 AI 生成审美，例如过度使用的字体族（Inter, Roboto, Arial）、陈词滥调的配色方案（特别是白色背景上的紫色渐变）、可预测的布局。

记住：设计应该根据需求而变化，不要在不同任务间趋同。如果是极繁设计，就需要复杂的动效代码；如果是精致极简，则需要对间距和排版有极高的克制力和精准度。优雅源于对愿景的出色执行。
