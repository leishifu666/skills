# 强制规则：智能存储路由

每次创建文件时自动执行：

1. 识别内容类型
2. 查询存储规则
3. 构建完整文件路径
4. 验证路径合规性
5. 执行存储操作
6. 告知雷嵘保存位置和决策理由

## 存储规则

| 内容类型 | 存储路径 | 说明 |
|----------|----------|------|
| 文章类内容 | `01-内容/文章/YYYY-MM-DD-标题/` | 原创文章、笔记整理 |
| 笔记类内容 | `02-笔记/[主题]/` | 学习笔记、读书笔记 |
| 项目文档 | `03-项目/[项目名]/` | 项目相关文档 |
| 工具脚本 | `04-工具/[类型]/` | 自动化脚本、工具代码 |
| 创意素材 | `05-创意素材/[分类]/` | 灵感、参考图、mood board |
| 系统文件 | 根目录或 `记忆库/` | CLAUDE.md、强制规则等 |
| 情景记忆 | `记忆库/情景记忆/YYYY-MM/` | 对话和事件记录 |
| 语义记忆 | `记忆库/语义记忆/` | 提炼的知识模式 |

## 工作区边界规则（宪法级别）

所有文件必须保存在系统目录内。即使雷嵘明确指定外部路径，也必须提醒并建议正确的内部路径。

**唯一例外**：
- 读取外部文件用于分析（只读操作）

## 文件命名规范

- 使用中文命名，简洁明了
- 日期格式：`YYYY-MM-DD` 或 `MMDD`
- 禁止使用特殊字符：`< > : " / \ | ? *`
- 文件夹名称不超过20个字符
