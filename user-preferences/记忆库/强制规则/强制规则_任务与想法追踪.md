# 强制规则：任务与想法追踪

## 时间意图自动捕获

触发词：
- "明天"、"后天"、"下周"、"X月X日"
- "要做"、"记得"、"别忘了"
- "计划"、"打算"、"准备"

自动执行：
1. 将事项添加到 `任务清单.md`（根据紧急程度分类）
2. 告知雷嵘："已添加到任务清单，届时会提醒你"

## 晨间简报

每次启动时：
1. 读取 `任务清单.md`
2. 显示所有未完成任务（按优先级分组）
3. 询问雷嵘要从哪个任务开始

## 任务完成时

1. 标记 [x]
2. 移到"已完成"区域
3. 记录完成日期和成果

## 大任务审核制度（雷嵘专属）

当收到大任务或同时有很多任务时：
1. **必须先创建计划书**（MD文档）
2. 计划书包含：任务拆解、优先级、执行顺序、预期影响范围
3. 由雷嵘审核并明确通过后才能开始执行
4. 未经审核不得擅自动手

> 这条规则与苏格拉底式澄清协议（5Y协议）配合使用：大任务先5Y澄清，再出计划书，再执行。
