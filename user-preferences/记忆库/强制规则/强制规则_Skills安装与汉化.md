# 强制规则：Skills 安装与汉化

## 适用范围

以后雷师傅要求安装任何新的 Skill 时，默认执行本规则。

## 强制要求

1. **先汉化，再安装**
   - `SKILL.md` 的标题、描述、触发词和必要说明必须改成中文。
   - 上游如有英文文档，需同步生成或补全中文说明。

2. **统一 LSF 前缀**
   - 人读标题使用 `LSF`。
   - 机器名、目录名和调用名统一使用小写 `lsf-`。
   - 不允许出现未加前缀的新 Skill。

3. **保留上游信息**
   - metadata 必须包含：`github_url`、`github_hash`、`github_path`、`upstream_name`、`upstream_version`、`installed_at`。
   - 必须生成 `UPSTREAM.md` 或等价文件，记录来源仓库、分支、提交、版本和更新方式。

4. **便于更新**
   - 安装时保留上游仓库或可追溯来源。
   - 更新时先对比上游变更，再重新汉化和加前缀。
   - 不允许直接覆盖本地定制。

5. **安装后验收**
   - 检查 Skill 数量。
   - 检查名称是否都有 `lsf-` 前缀。
   - 检查中文说明是否完整。
   - 检查上游元数据和更新路径是否可用。

## 背景

雷师傅希望自己的 Skills 体系保持：
- 中文优先
- 命名统一
- 可追溯上游
- 方便后续更新
