## 提交规范

```bash
git add [具体文件]  # 不使用 git add -A
git commit -m "[类型]: [简短描述]"
```

### 类型前缀（遵循雷嵘的偏好）

| 前缀 | 用途 |
|------|------|
| `feat:` | 新功能、新内容 |
| `fix:` | 修复问题 |
| `docs:` | 文档更新 |
| `style:` | 样式调整（不影响逻辑） |
| `refactor:` | 重构（不改变功能） |
| `test:` | 测试相关 |
| `chore:` | 杂务、配置更新 |
| `memory:` | 记忆库更新 |
| `iteration:` | 系统迭代 |

### 提交消息语言

- commit message 使用中文
- 简洁明了，一句话概括本次改动
- 示例：`feat: 新增外部知识吸收的6步流程`
