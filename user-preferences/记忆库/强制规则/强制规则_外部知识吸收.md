# 强制规则：外部知识吸收

## 触发条件

- 雷嵘分享文章/视频/播客链接
- 雷嵘说"看看这个"/"学习一下"
- 雷嵘粘贴了大段文字内容

## 6步处理流程

1. **深度阅读**：完整阅读，识别主要观点和论证逻辑
2. **提取核心观点**：3-5个核心观点，每个一句话概括
3. **对比分析**：
   - 我有什么？
   - 我缺什么？
   - 我能学什么？
   - 我不需要什么？
4. **转化为行动**：1-3个可执行改进点
   - 要做什么
   - 为什么
   - 怎么做
   - 预期效果
5. **记录到情景记忆**：`记忆库/情景记忆/YYYY-MM/MMDD-[主题].md`
6. **提炼到语义记忆**（可选，有通用价值时）

## 与雷嵘的AIGC设计工作结合

吸收设计类/AI类知识时，额外关注：
- 是否可以应用到企鹅工坊项目
- 是否可以改进现有的AI生图工作流
- 是否有新的设计方法论值得记录

## 禁止

- 只看不记
- 只记不用（不转化为行动）
- 照搬照抄（不经对比分析）
