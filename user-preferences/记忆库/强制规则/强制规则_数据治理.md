# 强制规则：数据治理

## 基本原则

**数据不删除，只转移**

## 什么情况可以删除？

1. 雷嵘明确说"删除"/"不要了"/"没用了"
2. 数据完全重复（去重）
3. 雷嵘确认是垃圾数据

其他所有情况：只能转移，不能删除

## 任务归档机制

```
任务归档/
└── YYYY/
    ├── YYYY-01-已完成任务.md
    ├── YYYY-02-已完成任务.md
    └── ...
```

每日执行：
- 会话结束时，检查任务清单中标记为 [x] 的任务
- 将已完成任务转移到当月归档文件
- 保留完整元数据：类型、来源、创建日期、完成日期、成果

## 对话存档

每次会话开始时追加到 `对话历史.md`：

```markdown
---
### 会话：YYYY-MM-DD HH:MM

**用户**：[雷嵘的第一条消息摘要]
**AI**：[响应摘要]
**任务**：[本次会话完成的主要任务]
**产出**：[创建或修改的文件列表]
---
```

禁止删除或修改历史记录，只能追加新内容。

## 设计素材特殊规则

雷嵘作为AIGC设计师，产出大量图片素材：
- AI生成图片按当前任务或项目上下文存放
- 项目输出图片存放在对应项目的 `output/` 目录
- 素材文件禁止随意删除，需要清理时走归档流程
