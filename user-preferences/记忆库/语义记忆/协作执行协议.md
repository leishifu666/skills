# 协作执行协议

> 生效日期：2026-03-25
> 目的：让雷嵘与 AI 的后续协作自动遵循第二大脑系统

## 默认判断顺序

每次收到新任务时，按以下顺序处理：

1. 先判断任务类型：纯执行，还是决策/方案/创作类。
2. 再判断影响范围：单文件、小范围、多文件结构性变更。
3. 再判断是否涉及记录：任务清单、对话历史、情景记忆、语义记忆、归档。
4. 最后决定执行方式：直接做、先澄清、先出计划书。

## 任务分流规则

### 纯执行类

直接执行，典型包括：

- 读文件
- 改一个明确位置
- 格式转换
- 查某个状态
- 启动一条待办

### 决策 / 方案 / 创作类

优先进入澄清流程，典型包括：

- 怎么设计
- 选哪个方案
- 如何规划系统
- 创意方向怎么定
- 规则怎么制定

如果是大任务，则顺序为：

1. 先澄清
2. 再出计划书
3. 等雷嵘确认
4. 再执行

## 记录规则

### 任务清单

出现以下内容时，应考虑加入或更新任务清单：

- 明天、后天、下周、某月某日
- 记得、别忘了、计划、准备、要做
- 明确表示后续还要继续推进的事项

### 对话历史

完成一次重要任务或形成阶段性成果后，应追加到 `对话历史.md`。

### 情景记忆

当出现以下情况时，应写入情景记忆：

- 有完整决策过程值得复用
- 解决了复杂问题
- 形成了新的合作模式
- 某次会话需要保留上下文和理由

### 语义记忆

当出现以下情况时，应沉淀到语义记忆：

- 提炼出长期有效的方法
- 形成了稳定规则
- 对系统理解显著升级
- 有可复用的执行框架

## 文件与操作规则

1. 不擅自删除用户内容，优先归档。
2. 不擅自改动目录结构。
3. 涉及 3 个以上文件的结构性变更，必须走审批流程。
4. 不擅自执行 Git 提交相关操作。
5. 代码与文档默认使用中文。

## 生图任务专用规则

1. 模型与分辨率按任务需求和项目能力选择，不固定单一模型。
2. 执行前先确认风格和比例。

## 当前协作结论

从 2026-03-25 开始，后续与雷嵘的协作默认按本协议执行，并结合第二大脑系统中的强制规则、任务机制和记忆机制共同生效。
