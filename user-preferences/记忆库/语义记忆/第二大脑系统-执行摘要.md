# 第二大脑系统执行摘要

> 生成日期：2026-03-25
> 用途：作为后续协作时的快速执行基线

## 一句话理解

这套系统不是普通笔记，而是雷嵘的数字化工作操作系统。核心目标不是“存文件”，而是让任务、规则、记忆、归档、上下文和执行流程形成闭环。

## 第一优先级规则

1. 必须全程使用中文，并称呼用户为“雷嵘”。
2. 大任务先澄清，再出计划书，经雷嵘确认后执行。
3. 不得擅自修改业务逻辑。
4. 不得擅自重组目录、移动文件或大规模结构调整。
5. 用户内容优先归档，不随意删除。
6. 不得擅自执行 Git 提交、force push、amend、`git add -A`。

## 12维度结构

1. 三层记忆：`记忆库/`，负责情景记忆、语义记忆、强制规则。
2. 智能存储路由：决定新文件该保存到哪里。
3. 任务追踪：由 `任务清单.md` 和任务追踪规则组成。
4. 上下文监控：要求每次回复检测上下文状态和指令遵循度。
5. 知识吸收：外部文章、视频、长文本要走 6 步吸收流程。
6. 数据治理：核心原则是“数据不删除，只转移”。
7. 5Y协议：决策类、创作类、方案类任务先澄清。
8. Git版本控制：只在明确授权下按规范提交。
9. 自我迭代：重大任务后可进入观察、分析、设计、实施、验证、记录、提炼、提交 8 步流程。
10. FATAL铁律：最高级别约束，不能违反。
11. 大任务审核：任务复杂时必须先出计划书。
12. 对话存档：重要会话要追加记录到 `对话历史.md`。

## 三层记忆的使用方式

- 情景记忆：记录具体事件、对话、决策原因。
- 语义记忆：沉淀通用规律、方法、长期有效认知。
- 强制规则：沉淀必须遵守的系统约束。

## 关键触发器

- 遇到“明天 / 后天 / 下周 / 计划 / 记得 / 别忘了”等时间意图：应进入任务清单。
- 遇到“看看这个 / 学习一下 / 链接 / 大段内容”：应启动外部知识吸收流程。
- 遇到“怎么做 / 选哪个 / 架构 / 方案 / 创作方向”：优先判断是否触发 5Y 澄清。
- 遇到结构性变更：必须走 `SCAN → PLAN → CONFIRM → EXECUTE → VERIFY`。
- 遇到生图任务：按任务与项目能力选择模型和分辨率，不固定 4K / `nano-banana (Pro)`。

## 后续默认工作方式

1. 先判断任务属于纯执行，还是决策/创作/方案类。
2. 纯执行类直接做，决策类优先澄清。
3. 涉及多步骤或高影响任务时，先形成计划书再推进。
4. 产出内容时，优先遵守智能存储路由和数据治理规则。
5. 完成重要工作后，视情况补充对话历史、情景记忆或语义记忆。
