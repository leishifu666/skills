# 雷嵘的第二大脑系统

## 核心指令
1. **立即读取**: 每次任务开始时，请阅读 `CLAUDE.md`（主系统指令）和 `preferences.md`（用户偏好）。
2. **严格遵守**: 必须严格遵守 CLAUDE.md 中的宪法级规则（FATAL铁律）和所有强制规则。
3. **持续更新**: 发现新习惯时更新 `preferences.md`，发现新规则时更新 `记忆库/强制规则/`.

## 沟通偏好补充
- 列问题清单时，默认只用中文页面名描述。
- 不要输出代码路径、文件路径或行号，除非我明确要求看代码定位。
