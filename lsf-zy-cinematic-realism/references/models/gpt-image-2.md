# LSF GPT Image 适配说明

本页整理提示组织方式，不保证具体版本、产品入口或接口参数。能力和产品边界以 OpenAI 当前官方说明为准。

## 适用任务

适合需要清楚场景描述、遵循多项约束、根据参考图生成或编辑图像的任务。先确认当前入口支持所需操作，再编写提示。

## 提示结构

1. 场景主体与当前动作。
2. 空间、构图和观看位置。
3. 光线、色彩、材质和媒介。
4. 用户指定的文字、比例和限制。
5. 参考图职责及每张图的边界。
6. 编辑任务中的保留项、修改项和区域。

使用自然、直接的制作说明。细节应互相一致；若多个要求竞争，明确优先级。不要重复堆叠同义形容词。

## 生成与编辑

- 新图：描述完整场景及视觉关系。
- 编辑：明确指出要变更什么、位置在哪里，以及周围哪些内容必须保持。
- 多张参考：分别说明身份、构图、媒介或风格职责。
- 可见文字：给出准确字句、语言、大小关系和位置；不能把“出现文字”当作完整指令。
- 多版本：保持共同事实不变，只改变用户授权的变量。

## 修复

如出现错误，描述具体位置和可见偏差，提出一个主要修复目标并列出保留项。提示正确但模型未遵循时，优先用更聚焦的编辑指令处理，不要推翻整份场景主档。迁移不同版本时先使用已验证的提示作为对照基线，再按用户要求调整。
