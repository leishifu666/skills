# LSF 模型能力对照

本页只提供任务选择框架，不是对当前模型功能、版本或参数的保证。产品能力会变化；涉及具体按钮、图像数量、编辑能力和参数时，查目标模型的最新官方说明。

| 任务类型 | 路由关注点 |
| --- | --- |
| 从文字生成 | 明确主体、动作、空间、媒介和用户限制；按模型习惯组织简报。 |
| 依据参考图生成 | 先分配每张参考图职责，检查身份、构图、媒介和风格权限是否冲突。 |
| 编辑现有图 | 划定获准修改区域，说明目标变化和必须保留的内容。 |
| 局部修复 | 只描述瑕疵位置、修复目标及边界，避免影响已正确区域。 |
| 多图合成 | 明确每张图提供的元素及其空间关系，不要把来源图的其他内容带入。 |
| 多版本输出 | 锁定所有共同事实，每版只改变用户要求的变量。 |

## 适配原则

模型的提示理解差异只决定表达形式，不改变场景主档。不能因为模型偏好某种媒介，就擅自将用户指定的绘画、平面设计或动画改成摄影。若模型不遵循指令，先识别具体失败，再决定局部编辑、简化提示或换用合适工具。
