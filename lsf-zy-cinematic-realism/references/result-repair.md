# LSF 生成结果修复

修复从可见失败开始，不重写已经正确的部分。

## 诊断顺序

1. 将结果与场景主档逐项对比：主体、动作、空间、构图、光线、材质、比例和文字。
2. 把问题归类为事实错误、空间错误、视觉语法偏差、模型执行偏差或技术瑕疵。
3. 找出最小且明确的修正目标，说明它出现的位置及要达到的结果。
4. 明确哪些内容必须保留，哪些区域允许改动。
5. 选最适合的手段：改提示、局部编辑、遮罩修复、重新生成或调整模型表达。
6. 修复后检查没有引入新人物、道具、文字或场景变化。

## 修复指令格式

- **现象：** 具体描述可观察的问题。
- **位置：** 指出画面中的区域或对象。
- **目标：** 说明应变成什么样。
- **保持：** 列出不可改变的内容。
- **边界：** 限定编辑区域及不应波及之处。

一次优先修复一个主要问题。若模型持续忽略明确要求，改用更直接的局部编辑或适配语法，不要不断叠加形容词。无法判断的问题应标出不确定性，不伪称已修复。
