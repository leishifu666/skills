# LSF 参考图职责路由

多张参考图必须先分配职责，再分析其视觉信息。没有明确职责的参考图可能互相冲突，或把原图故事带入新场景。

## 职责类型

- **身份：** 只控制人物或物体的识别特征。
- **构图：** 控制画面布局、主体位置和空间关系。
- **媒介：** 控制图像制作方式及其视觉限制。
- **风格语法：** 控制可观察的色彩、材质、明暗、边缘和形式规律。
- **文字或标识：** 控制必须准确呈现的字句、标志及位置。
- **编辑底图：** 作为需要保持并局部修改的现有图像。

## 操作顺序

1. 按用户原话记录每张图的职责；没有指派时，只做保守推断。
2. 指出职责冲突，例如两图都指定了不同构图或不同媒介。
3. 明确每张图不能控制的内容，尤其人物、服装、动作、道具、地点、品牌和文字。
4. 对身份参考，保留身份而不自动继承姿势、服装和背景。
5. 对风格参考，提取制作规律，不复制原图主体或故事。
6. 对编辑底图，列明必须保留的内容和唯一获准修改的区域。
7. 编译后逐图检查其权威边界，确认没有串用信息。

用户明确赋予参考图的职责高于系统推断；如参考之间不可兼容，先说明冲突，不擅自混合。
