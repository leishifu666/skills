# LSF 媒介选择路由

先确定画面由什么媒介和制作方式形成，再编写模型提示。电影摄影只是一个选项，不是默认答案。

## 判断流程

1. 读取用户明确指定的媒介：照片、电影静帧、油画、版画、漫画、动画、海报、产品图或其他形式。
2. 若用户没有指定，依据用途和参考图做最少推断；存在实质歧义时，选择最贴近用户表达的方案。
3. 将媒介转换成可执行特征：线条、笔触、色块、纸张、网点、边缘、运动方式、反射、景深或渲染逻辑。
4. 检查参考图是否拥有媒介决定权。被指定为构图或人物参考的图，不应自动控制媒介。
5. 将媒介限制写入场景主档，并保持到目标模型提示词中。

## 典型约束

- **摄影：** 镜头位置、光源、曝光、焦点、景深和材质须相互一致。
- **绘画或版画：** 说明形体、笔触、颜料、纸面、边缘和色彩组织，避免默认加入摄影景深。
- **动画或漫画：** 描述角色设计、线条、分镜、动作阶段和背景绘制方式。
- **平面设计：** 优先确定版面层级、网格、文字内容、留白和印刷关系。
- **三维图像：** 明确渲染用途和材质，但不以通用写实渲染覆盖其他媒介特征。

若用户明确要求“电影化改编”或“写实摄影转译”，才可改变原媒介；同时保留其视觉核心，并说明媒介转换。
