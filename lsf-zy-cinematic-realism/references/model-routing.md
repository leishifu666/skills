# LSF 模型路由

选择目标模型后再编写其原生提示。不同模型的提示形态可以不同，但场景事实、参考职责和有效视觉规则必须一致。

## 路由步骤

1. 确认目标模型及其可用版本。版本和参数可能变化，使用前以模型当前官方说明为准。
2. 判断用户要生成新图、编辑现有图、局部修复、扩图还是组合多张参考图。
3. 先完成场景主档和参考图职责，再调用对应模型适配说明。
4. 使用目标模型习惯的自然语言结构、参数和编辑表达，不把一个模型的提示逐字翻译成另一个模型格式。
5. 编译后对照锁定事实，检查人物、动作、空间、比例、文字和限制没有变化。

## 模型参考

- GPT Image 系列：结构清晰的制作简报；图像编辑时明确保留项和改动区域。
- Midjourney：具体、凝练的视觉描述；区分普通生成与图像编辑，并只添加当前支持且确有需要的参数。
- Seedream：空间关系清楚的创作简报；编辑时指出区域、目标及保持不变的部分。
- Nano Banana：直接说明要生成或编辑什么，清楚划分“保留”和“修改”。

模型名称和能力以各自最新官方文档为准；若本地适配页与官方当前版本冲突，保留场景逻辑并更新目标语法。
