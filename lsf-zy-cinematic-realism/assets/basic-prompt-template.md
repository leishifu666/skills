# LSF 基础提示模板

使用时只保留适用于当前任务的字段。方括号内容需要替换或删除，不要原样提交。

## 场景

- **主体与身份：** [谁或什么]
- **当前动作：** [画面中正在发生什么]
- **关键瞬间：** [动作前、动作中或动作后的哪一刻]
- **空间：** [地点、前景、中景、背景及可行路线]
- **人物关系：** [站位、视线、距离、互动]
- **视觉中心：** [观众先看见什么]

## 视觉制作

- **媒介：** [摄影、绘画、动画、平面设计等]
- **观看位置与构图：** [摄影机或视点、景别、画面组织]
- **光线与明暗：** [光源、受光区域、阴影与曝光]
- **色彩与材质：** [来源、表面反应、磨损或纹理]
- **时间与天气：** [仅填写相关内容]

## 约束

- **必须保留：** [用户锁定内容]
- **允许变化：** [获准变化的部分]
- **可见文字：** [准确内容及位置；没有则删除]
- **比例：** [指定比例]
- **排除项：** [三至五项针对性风险；没有则删除]

将信息改写成目标模型的原生形式。避免空泛赞美词和与场景无关的镜头术语。
