## 1. 蒙太奇模式

这些是解决常见场景类型的预制结构。挑一个，填入你的具体内容。

### 模式 1。升级

用于紧张构建、揭示、戏剧强调。

```text
wide -> medium -> close-up -> macro -> reaction close-up -> impact
```

### 模式 2。焦虑

用于心理压力、内心冲突、即将到来的坏消息。

```text
face -> object -> hand -> face -> object closer -> sound cue -> sudden stillness
```

### 模式 3。发现

用于揭示隐藏元素、探索、搜寻。

```text
POV -> empty space -> searching hand -> hidden object -> rack focus -> emotional reaction
```

### 模式 4。灾难

用于喜剧或戏剧性灾难。微小物件的失败比爆炸更戏剧化。

```text
anticipation -> object instability -> reaction -> object falling -> impact -> silence -> emotional collapse
```

### 模式 5。商业产品戏剧

用于有主角产品的广告。

```text
lifestyle setup -> product reveal -> macro texture -> human reaction -> use moment -> hero product shot
```

### 模式 6。MV 循环

用于节奏性重复、转变、表演。

```text
gesture A -> cut -> gesture A from new angle -> cut -> transformation -> repeat gesture A -> release
```

## 2. 类型模块

每种类型都有独特的视觉语法。让风格与节奏匹配类型。

### 家庭悲剧

普通物件被极度严肃对待。微小事件成为宇宙级灾难。

- 风格。冷夜室内。平凡地点。戏剧性特写。慢推近。微距插入。突然的静默。
- 基调。悲喜交加。荒谬的真诚。
- 节奏。慢构建、更长的反应镜头。
- 示例。一个男人发现自己冰箱空了，演成希腊悲剧。

### MV

节奏。重复。视觉母题。转变。

- 风格。重复手势。match cut。表演片段。视觉循环。配色分区。激进换镜。
- 基调。情绪强度。可读结构下的感官过载。
- 节奏。快、拍点驱动。

### 商业广告

清晰。产品逻辑。感官细节。

- 风格。干净灯光。有目的的微距。产品清晰可见。克制运动。可读的最终主角镜头。
- 基调。欲望。转变。用动作展示利益。
- 节奏。中速，推向主角镜头。

### 心理剧

压力。静止。负空间。

- 风格。锁定画面。长特写。倒影。遮挡式取景。安静的声音设计。
- 基调。内心冲突。隐藏紧张。情绪压缩。
- 节奏。慢，持续。

### 动作

空间清晰高于一切。

- 风格。确立地理。清晰的运动方向。冲击插入。特写之间的广角。强视线连贯性。
- 基调。紧迫。力量。可读的混乱。
- 节奏。快但几何清晰。

### 竞速/速度

真实的快。无面孔的细节即情绪。冷战斗色板。

- 风格。低保险杠高度。画面中沥青拖影。前景参考物掠过。金属/橡胶/汗上的硬光。向起跑收缩的节拍锁定剪切。
- 基调。威胁，而非炫目。力量传递胜过闪亮车身。
- 节奏。静默-然后-爆发。持守的仪式、爆炸的起跑、密集的对抗、一次持守的余波。
- 完整语法（流派、起跑线仪式、5 镜头家族、漂移改编、防伪守卫）加载 `race-and-speed.md`；转静帧面板加载 `animatic-keyframes.md`。

### 时尚

对称取景。克制色板。重复剪影。

- 风格。慢动作微节拍。微距面料细节。自信的静止。轮廓光。
- 基调。笃定。性感。
- 节奏。慢，刻意。

### UGC / 社媒

真实。竖屏。快。

- 风格。手持。自然光。9:16。竖版构图。面向镜头的手势。快节拍。
- 基调。即时。随意。紧迫的相关性。
- 节奏。极快，缩略图可读。

## 3. 多片段故事结构

AI 视频生成器在两次生成之间没有记忆。更长的视频活在剪辑拼接的多片段里。

### 默认拆分

- 10 秒。2 段 x 5s
- 15 秒。3 段 x 5s
- 30 秒。6 段 x 5s
- 45 秒。9 段 x 5s
- 60 秒。12 段 x 5s

例外。Seedance 多镜头可在一条 5-10 秒片段里放入 2-3 个镜头。

### 每条片段必须重复的东西

每条片段自包含。模型没有记忆。在每条片段里重复这个模块。

- 角色身份（脸、发、服装、标志性特征）
- 服装单品，确切命名
- 地点描述
- 视觉风格（色板、调色、参考）
- 运镜语言（整支片子的主导语法）
- 灯光逻辑（主导光源与方向）
- 连贯性规则（什么必须保持恒定）
- 带具体颜色的色板

对，每一条片段。对，即使感觉重复。那份重复是保住输出一致的唯一东西。

### 带时间码的内部节拍

在每个 5 秒提示词内部，使用时间码。

```text
0.0-0.8. [action / camera / light]
0.8-1.6. [action / camera / light]
1.6-2.5. [action / camera / light]
2.5-3.7. [action / camera / light]
3.7-5.0. [action / camera / light]
```

按类型的密度。

- 情绪剧情。每 5 秒 3-4 个节拍。更长的反应。
- 标准叙事。每 5 秒 4-7 个节拍。
- 快速蒙太奇 / MV。每 5 秒 6-9 个节拍。

Seedance 和 Veo 用时间码结构。Kling 偏好流畅散文。

### 跨片段连贯性

从片段 N 移到片段 N+1 时，新片段的首个节拍应匹配上一片段的最后节拍。相同姿势。相同光。相同色温。这就是它们在剪辑器里能干净接在一起的原因。

示例。片段 1 结束于他伸手进冰箱。片段 2 开头是他的手在冰箱内、同一高度同一光线。
