算法哲学是计算美学运动，随后通过代码表达。输出 .md 文件（哲学）、.html 文件（交互式查看器）和 .js 文件（生成算法）。

这分为两个步骤：
1. 算法哲学创作（.md 文件）
2. 通过创建 p5.js 生成艺术来表达（.html + .js 文件）

首先执行此任务：

## 算法哲学创作

首先，创建一个算法哲学（不是静态图像或模板），它将通过以下方式解释：
- 计算过程、涌现行为、数学美感
- 种子随机性、噪声场、有机系统
- 粒子、流、场、力
- 参数变化和受控的高级混沌

### 核心理解
- **接收到的信息**：用户提供的微调输入或指令，但应将其作为基础；它不应限制创作自由。
- **创建的内容**：一种算法哲学/生成美学运动。
- **接下来的步骤**：同一版本接收哲学并用代码表达它 - 创建 90% 是算法生成、10% 是基本参数的 p5.js 素描。

考虑以下方法：
- 为生成艺术运动撰写宣言
- 下一阶段涉及编写将其变为现实的算法

哲学必须强调：算法表达。涌现行为。计算美感。种子变化。

### 如何生成算法哲学

**命名该运动**（1-2 个词）：例如“有机湍流”、“量子谐波”、“涌现寂静”

**阐述哲学**（4-6 段 - 简洁但完整）：
为了捕捉算法精髓，表达这种哲学如何通过以下方式体现：
- 计算过程和数学关系？
- 噪声函数和随机模式？
- 粒子行为和动力场？
- 时间演变和系统状态？
- 参数变化和涌现复杂性？

**核心准则：**
- **避免冗余**：每个算法方面应只提一次。避免重复提及噪声理论、粒子动力学或数学原理，除非增加了新的深度。
- **反复强调匠心**：哲学**必须**多次强调，最终算法应看起来像是经过无数小时开发、精心打磨，且出自该领域顶尖专家之手。这种框架至关重要 - 重复使用诸如“精心打磨的算法”、“深度计算专业知识的产物”、“艰苦的优化”、“大师级实现”等短语。
- **留出创意空间**：明确算法方向，但要足够简洁，以便让下一次实现时有空间进行极高水平的解释性实现。

哲学必须引导下一版本通过代码表达创想，而不是静态图像。美存在于过程之中，而非最终的画面。

### 哲学示例

**“有机湍流” (Organic Turbulence)**
哲学：受自然法则约束的混沌，秩序从无序中涌现。
算法表达：由分层 Perlin 噪声驱动的流场。数千个粒子遵循矢量力，其轨迹累积成有机密度图。多个噪声倍频程创建湍流区域和冷静地带。颜色源自速度和密度 - 快速粒子闪耀，慢速粒子淡入阴影。算法运行直到达到平衡 - 一种精心调优的平衡，每个参数都由计算美学大师经过无数次迭代精炼而成。

**“量子谐波” (Quantum Harmonics)**
哲学：表现出类似波的干涉模式的离散实体。
算法表达：初始化在网格上的粒子，每个携带通过正弦波演化的相位值。当粒子相互靠近时，其相位会发生干涉 - 相长干涉产生亮点，相消干涉产生空洞。简单的谐波运动产生复杂的涌现曼陀罗。这是艰苦频率校准的结果，每个比例都经过精心选择以产生共振美感。

**核心原则：**
- **算法哲学**：创建一种通过代码表达的计算世界观。
- **过程高于产品**：始终强调美感源自算法的执行 - 每次运行都是独一无二的。
- **参数化表达**：创想通过数学关系、力、行为进行交流，而非静态构图。

## P5.JS 实现

在建立了哲学和概念框架后，通过代码将其表达出来。

### ⚠️ 步骤 0：先阅读模板 ⚠️

**核心：在编写任何 HTML 之前：**
1. 使用 Read 工具阅读 `templates/viewer.html`
2. 研究其确切的结构、样式和 Anthropic 品牌化
3. **将该文件作为字面意义上的起点** - 而不仅仅是灵感
4. **保持所有固定部分完全一致**（页眉、侧边栏结构、颜色/字体、种子控制、操作按钮）

## 侧边栏结构说明

**1. 种子 (固定)** - 始终完全照搬：
- 种子显示、前一个/后一个/随机/跳转按钮

**2. 参数 (变量)** - 为艺术创作控制：
- 滑块、输入框等

**3. 操作 (固定)** - 始终包含：
- 重新生成、重置、下载 PNG 按钮

**核心提醒**：
- **模板是起点**，而不是灵感。
- **算法是发挥创意的地方**。
- 保持 Anthropic 的品牌化和 UI 结构。
