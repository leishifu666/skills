# 上传参考片 → 可组合的导演素材库

用户上传视频、指定已有参考或希望「像这支但换成我的产品」时读取。入口工具：scripts/ingest_reference.py；结构化检索目录：assets/motion-library/index.json；可执行原创配方：assets/motion-library/recipes.mjs。

## 入库不是拷贝成片

保存三层资料：

1. **证据**：来源、授权/使用范围、文件 SHA256、尺寸/FPS/时长、片段时间码、关键帧和已观察范围。私人上传原片留在用户指定本地目录；第三方原片不默认复制到可分发 skill
2. **技法卡**：运镜、动效、视觉特效、缓动/速度、剪辑、声音分别拆开，说明它服务什么信息、依赖什么前后状态、何时不适用
3. **可组合配方**：自己的 GSAP/遮罩/剪辑/声音事件参数与实现，接收产品素材、真实 UI 边界和时间；不携带别人品牌、UI、文案、音乐或海报。收进 skill 的是可迁移的技法与原创实现

## 实际拉片

- 先探测媒体。全片 1–2 fps 通览，只能标记段落候选；转场 8–12 fps，关键边界再提取原帧率。看连续段落与出入镜，不能只凭封面还原动画
- 标注场景任务、对象 ID、前/中/后三个状态、屏幕坐标、裁切、缩放、层次、遮挡、字幕与指针、声音起止和停顿。音轨须实际听审才判断音色与质感
- 相机运动与物体运动分轨：画面整体移动不必然是摄影机；没有工程文件就不能确定用什么软件/插件
- 记录关键时刻的归一化位移 p(t)；有限差分估计速度/加速度，量测范围和误差保留。存在运动模糊、遮挡或采样稀疏时降置信度。用 GSAP 重做的 ease 是近似或自定，除非源项目明确提供，不宣称知道作者原始曲线
- 识别剪辑：切在动作中、图形匹配、方向匹配、景别变化、遮挡擦除、形变、溶解、速度重映射、J/L 声音跨镜；每种分别解释语义与接口，不能统一记为「丝滑转场」

## 技法卡必填

`id / tags / intent / source / timeRange / viewedRange / sampleFps / observed / inferred / confidence / inputContract / outputContract / tunables / recipe / doNotCopy / licenseScope`

输入/输出契约至少含：承接对象身份、焦点位置、移动方向、可见范围、出入速度、是否处于接触/输入、背景关系、声音尾部是否仍在。

视频/图板是研究证据，原创代码是可复用工程资产，音频样本是另一类授权资产。三者不得混成一个「免费素材包」。用户提供素材不等于拥有所有版权；本地分析与直接用于我方成片分别处理，不因这一点阻塞常规本地研究。

## 两种使用模式

**自由组合**：先读 product-brief 和 director，再按当前段落意图检索技法卡（聚焦输入、看结果、空间迁移、结尾等）。检查前一张卡 outputContract 与下一张 inputContract；对象、方向、速度不匹配时增加过渡段或换卡。避免相同大动作连续堆叠。先试最难的相邻两段，再排全片

**指定参考重新导演**：保留参考的运动语法、节奏对比与关键承接关系，把剧情、产品事实、页面、素材和文案换成自己的。逐段写「原参考目的 → 新产品目的 → 保留的技法 → 改写的叙事」。如果产品必须读字/等反馈，允许拉长该段，不能为对齐原片时长删掉因果。除非用户明确要逐镜复刻，不默认一一复制构图与顺序

## 从样本到入库

先用真实产品输入跑 5–12 秒样本；审查接触、读屏、镜头方向和接缝，再把状态从 `candidate` 改为 `tested`，并记录测试产品与限制。自动抽帧完成只能得到 `unreviewed`，自动数值测试不能把它升级为审美通过。

当前目录中的曲线/时长是原创工程起点，不是从参考片精确反演的数据。优先调距离与阅读时间，再调整速度形状；真实按钮反馈仍沿用项目本身。
