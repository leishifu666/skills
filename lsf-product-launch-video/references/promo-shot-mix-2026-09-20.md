## 先分配镜头任务，再画镜头

1. 写一句本片承诺和观众应记住的成果，例如“一杯奶茶，变成能展示的产品海报”。
2. 给每个候选镜头标注角色：`hook` 注意、`claim` 主张、`proof` 操作证据、`payoff` 成果、`context` 使用情境、`brand` 品牌。角色是原创工作约定，不是原作者术语。
3. 先问“这一镜改变观众的什么理解”，再选表现形式：真实 UI、独立文字、作品特写、图形概念、应用样机、人物/场景。界面操作只占其中一种；不机械规定比例，也不为了达标硬塞无关形式。
4. 连续操作只保留理解因果必需的节点。多个设置过程表达同一件事时，删掉重复操作或用剪辑压缩；不要统一加速鼠标或缩短全部读屏时间。
5. 为相邻镜头写连续线索：同一主体、文字承接、动作结果、相同方向、构图锚点或空间来源。插镜必须承接故事，不能只说“这里需要炫酷”。
6. 先用镜头卡检查全片：如果删掉 UI 后几乎没有故事信息，通常仍是操作演示；如果删掉 UI 后功能说法没有证据，则作品/概念过量。按当前传播目的修正，不把任何一种比例当通用标准。
7. 在动态分镜中检查读屏停顿、快速变化和成果停留的反差，再进入 GSAP 实现。真实项目交互保持原实现，独立 MG 镜头明确属于影片编排。

## pen-proof-intercut

- 来源：[Pen · Tom Krcha](https://x.com/tomkrcha/status/2100570466692071493)，33.13 秒，片尾 `pen.dev`；发现目录使用 Pencil 名称。
- 观看：全片 1 fps；15.5–20.5 秒以 12 fps 查看，近似到采样网格，非原帧精确切点。
- 观察：独立文字 → 输入特写 → `edit` → 发送特写 → `with agents` → 多个设计结果。若干接缝直接切换，读屏和结果仍各有停留。全片另有金属 Import 物件、独立文字与模型标识镜头。
- 复用方法：围绕同一个任务，把动作证据和价值短句交叉，结果承担段落落点；不是在每个按钮后都插一张字卡。
- 输入契约：观众已经知道要做什么；输入镜头中的素材、意图能被识别。
- 输出契约：看到了该操作导致的结果；短句没有暗示未实现能力。
- 可调参数：每句信息量、界面读屏停留、插镜次数、结果停留。按自己的文案重新编排，不抄约 1 秒的参考节奏。
- 坤坤迁移：奶茶参考图进入真实 Agent 输入 → 独立短句强调目标 → 真实提交与可见协助 → 海报结果。
- 限制：参考视频画面不证明作者直接挂载原生组件；不照搬金属按键、文案、模型 logo、声音或完整镜头顺序。原缓动未知。

## arrow-object-application

- 来源：[QuiverAI · Arrow 2](https://x.com/QuiverAI/status/2100295136261349802)，43.88 秒。
- 观看：全片 1 fps；21.4–26.4 秒以 12 fps 查看。
- 观察：奔跑姿态序列约在 23.2 秒进入单只豹的应用蒙太奇；鞋、服装、杯子、帽子、手机等载体快速变化，豹的身份与向右方向保持可识别。不是每一刀都有完全相同的大小或坐标，也未测得帧精确切点。
- 复用方法：建立一个视觉主角，用同一作品跨越载体和材质。快切的连续性来自主角和构图，不需要每一刀都加推拉或 whoosh。
- 输入契约：作品已可识别；待展示应用确实使用同一主角/设计。
- 输出契约：观众知道作品可在何种情境被使用，而不是看到一串无关图片。
- 可调参数：主体在画幅中的锚点、占比、朝向、裁切、载体数量和停留长度。复杂应用多留时间；不要用同一速度机械翻图。
- 坤坤迁移：同一杯奶茶 → 同款海报主视觉 → 店内灯箱 → 手机展示 → 完整海报。店铺/灯箱是作品应用示意，不把其制作过程冒充产品具备的功能。
- 限制：原片实物/样机的制作方法未知；不复制豹图、第三方商标、原音轨或具体样机素材。

## linear-concept-to-symbol

- 来源：[Linear · Loops](https://x.com/linear/status/2079233260161323371)，40.45 秒。
- 观看：全片 1 fps；25.5–28.5 秒以 12 fps 查看。
- 观察：任务标签围绕环轨展开，多个环在深度方向交叠；加密片段显示拉远时标签消退、环轨收束成中央符号。原曲线、镜头焦距和三维软件未知。
- 复用方法：先用图形讲清功能关系，再减少细节、收束焦点；可以把一段复杂概念压成一个可记忆画面。
- 输入契约：图形中的每条连线/关系对应真实产品逻辑；观众有足够线索理解它。
- 输出契约：视觉复杂度下降，落到一个清晰结果或符号；必要时回真实 UI 验证。
- 可调参数：层数、视点、信息密度、细节消退时间、收束对象。坤坤不照搬 Linear 的环轨形式。
- 坤坤迁移：把“奶茶参考图 + 创作目标 → Agent 协助 → 可编辑海报结果”短暂变成影片图形，再交回真实画布。不能杜撰并行生成、自动排版或模型协作能力。

## 奶茶片的原创结构方向

海报成品钩子 → 回到这一杯奶茶 → 真实输入/引用 → 独立文字与构图展开 → 真实 Agent 协助 → 同款海报进入应用情境 → 品牌收尾。

这只是结构迁移建议，未制作 V9，不构成新的成片验证。真实 UI 的 hover、焦点、连接与反馈继续按项目实现；独立 MG 插镜改变影片表达，不改变或假造产品功能。选择新镜头时仍需核对当前代码能力与素材身份。
