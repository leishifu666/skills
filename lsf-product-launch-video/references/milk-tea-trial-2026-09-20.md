# 奶茶海报：产品理解、参考组合与原生交互试跑

产品：坤坤魔法 1.4.25，试跑目录 `D:/Penguin-Magic_7.0/Penguin_Magic_main/outputs/kunkun-product-video-v8`。本机工程入口，不是跨机器通用依赖

## 原创故事

奶茶原图 → 原生画布 → Ctrl+引用给 Agent → 输入焦糖海报需求 → Agent 的会话演示调用真实 canvas.apply 控制器生成节点与直接参考连线 → 用户检查结果 → 物品分类保存资产 → 同一图片转入海报特写

一张原图直接作为 Codex 内置生图工具的参考生成海报，保持主体一致。没有把其他品牌海报或不相关素材拼到产品中

## 参考如何迁移

- Screen Studio 的聚焦—读屏—退出关系：镜头先到输入框，分组输入后停顿，再发送并拉回
- Apple 的空间来源关系：记录首页图像、画布图像、资产缩略图的真实边界，同一张图跨场景承接
- Bohdan 的输入与提交节奏对比：保留读取需求的时间，发送之后才发生镜头变化和结果，不照抄原片速度或文案
- Lark 的对象层次错开：结果与原图同时存在、分层接入、主海报前移，避免逐张幻灯

这次实际使用了库中的原创 quintic 曲线；focusReadRelease / sameObjectHandoff / directionalLayerPass 配方分别做了端点与保持段执行验证。成片的对应关系针对原生 DOM 矩形另行编排，不能说三个封装函数全部在成片中被直接调用

## 已验证与限制

54 秒、3240 帧、1920×1080、60 fps；完整解码通过；146 个当前组件/上下文源码 hash 匹配；原生输入前存在引用 chip，发送携带 milk-reference；最终 3 节点、2 连接，原图直接连到海报；原生资产保存物品分类；JS 异常 0

发现保存弹层消失后的误匹配导致约 685 px 单帧跳位，修正容器限定和丢失目标后的跟踪；最终可见光标最高 1821.87 px/s，按本片 1080p 选定 2200 px/s 预算验证。该预算不是通用人机标准，也不等于观感自然

42 个授权采样事件与音乐混音；最终 AAC 实测约 −16.15 LUFS、−1.58 dBTP。未主观听审。模型会话与生图返回为演示回放，未执行在线 Agent/模型。当前 UI 控制器未改写，转场的原图遮挡属于编辑层

参考入库脚本用已有 Screen Studio 本地文件 0–1 秒试跑，得到 12 帧和 SHA256/媒体元数据；输出状态仍为 unreviewed。数值测试与抽帧完成不应自动升级为审美通过，技法卡仍保留 candidate，等待正常速度下的观感确认
