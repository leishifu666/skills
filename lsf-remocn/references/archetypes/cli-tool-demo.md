# 命令行工具演示

**类型：**开发者工具　**时长：**约 18–45 秒　**画幅：**16:9

终端是主画面：输入真实命令，按步骤展示少量输出，再呈现成功结果。AI 工具可以增加对话镜头；纯 CLI 不必加入聊天界面凑时长。

## 镜头节奏
短版：钩子 → 命令运行 → 结果 → 品牌收尾。标准版可加入提示词或智能体界面。终端输出按离散步骤出现，不平滑滚动；每段显示 3–6 行，突出最后的成功状态。

## 组件建议与内容
可组合 `terminal-simulator`、`rolling-number`、`check-list`、`typewriter` 和适配工具生态的聊天组件。网页结果需要外框时新增可复用的 `browser-frame`。准备工具名、真实命令、真实输出和结果类型；只用一两个可核验数字。
