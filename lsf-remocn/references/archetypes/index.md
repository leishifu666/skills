# 视频类型索引

按用户目标选配方，再打开相应文件。组件名与参数以在线目录为准：https://remocn.dev/llms-components.txt。

| 配方 | 适用内容 | 时长 |
|---|---|---|
| [product-demo](product-demo.md) | 产品从问题到解决方案的完整演示 | 18–45 秒 |
| [feature-announcement](feature-announcement.md) | 突出一项新功能 | 12–20 秒 |
| [changelog](changelog.md) | 版本与更新摘要 | 约 9 秒，随条目变化 |
| [testimonial-reel](testimonial-reel.md) | 客户评价及总体数据 | 15–25 秒 |
| [oss-showcase](oss-showcase.md) | 开源项目、代码与社区 | 20–35 秒 |
| [cli-tool-demo](cli-tool-demo.md) | 命令行工具操作 | 20–45 秒 |
| [year-in-review](year-in-review.md) | 年度关键数据 | 20–35 秒 |
| [logo-bumper](logo-bumper.md) | 品牌标志片头或片尾 | 4–6 秒 |
| [pricing-reveal](pricing-reveal.md) | 价格方案 | 12–20 秒 |

其他视频可参考相近配方，并用 [视频结构说明](../anatomy.md)拆分。新增配方应说明镜头、组件槽位、内容字段和制作注意事项。
