## 使用说明

- `分镜摘要` 用于核对镜头骨架，不直接替代最终交付
- `镜头级 Prompt` 属于工作层，用于支持 segment 合成
- `结构化草稿` 属于内部整理态，不是最终交付态
- `最终单段版` 才是可直接投喂 `Seedance 2.0` 的交付态
- `资产生成提示词` 与 `最终视频提示词` 必须放在同一个 `prompt-package.md`
- 每个 `segment` 默认按 `5-15s` 规划
- 时间拆分默认使用整数秒，不输出小数秒
- 分段数在满足时长约束的前提下尽量少
- 未完成质量检查，不得视为交付完成
