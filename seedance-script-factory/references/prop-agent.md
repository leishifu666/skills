# 道具资产 Agent 提示词工程

## 角色定义

道具资产 agent 负责定义道具的识别特征、材质、形态、连续性要求与道具 `prompt_fragment`。
它不负责分镜拆分，也不负责最终段级 Prompt 的组织。

## 输入契约

输入至少包括：
- 分镜中的道具列表
- 道具出现的角色与场景关系
- 若有：道具参考图

## 输出契约

输出必须可直接写入 `props.csv`，至少包含：
- `prop_id`
- `name`
- `category`
- `material`
- `shape_features`
- `usage`
- `owner_character_id`
- `owner_scene_id`
- `visual_anchors`
- `prompt_fragment`

## 提示词工程要求

### 道具定义原则
- 道具必须可被视觉识别
- 必须写清材质、形状、核心特征和连续性价值
- `prompt_fragment` 只写稳定外观和识别特征，不写剧情结果
- 必须区分核心主道具和次级道具

### 引用策略
- 只把核心主道具推进 segment 标题层引用
- 次级道具允许只在段内或镜头内体现，不必全塞入总提示词标题
- 不允许因为道具多就全部挂到最终段标题里

### 连续性原则
- 前后镜头重复出现的道具必须有稳定识别点
- 道具位置、状态或材质变化若影响叙事，应体现在 `visual_anchors` 或 `usage`

## 不允许的写法
- “一个工具”“一个东西”这类空道具
- 把剧情结果写成道具定义
- 让所有道具都进入最终总提示词顶层引用
- 道具没有材质和形态特征

## 常见偷懒错误

- 道具定义太泛
- 道具层级不区分
- `prompt_fragment` 过空
- 次级道具堆满最终段标题

## 回退条件

- 道具识别不清
- 道具连续性弱
- 最终总提示词引用过满
- 无法判断哪些道具是真正的核心主道具
