# 工作流

## 目标

把剧本文本、脚本大纲、分镜表、shot list、已有 Prompt 或混合素材，整理成适配 `Seedance 2.0` 的完整生产包。

## 协调原则

总控层先决定：
- 输入属于剧本、分镜、已有 Prompt 还是混合输入
- 哪些任务可以并行
- 哪些任务必须等待上游结果
- 哪些结果必须通过质量 gate 才能进入交付
- 当前产物属于镜头级、结构化草稿（内部整理态）还是最终交付态

## 输入类型判定矩阵

| 输入类型 | 首站模块 | 必经步骤 | 可跳过步骤 | 最小交付要求 | 回退入口 |
| --- | --- | --- | --- | --- | --- |
| 原始剧本 / 梗概 / 脚本 | 总控层 → 分镜 agent | 分镜骨架、资产库、Prompt 整合、质量 gate | 不可跳过分镜 | 完整生产包 | 分镜 agent / 总控层 |
| 已有 storyboard / shot list | 总控层 → 字段规范化流程 | 字段规范化、资产补齐、Prompt 整合、质量 gate | 可跳过从零拆剧本 | 完整生产包 | 分镜 agent |
| 半成品生产包 | 总控层审计缺口 | 缺口补齐、Prompt 校正、质量 gate | 可跳过已合格模块 | 缺口补齐后的生产包 | 缺口所属模块 |
| 已有镜头 Prompt / 结构化草稿（内部整理态） / 最终单段连贯总提示词 | 总控层判定层级 | 缺失层级补齐、最终交付压缩、质量 gate | 可跳过已存在且合格的上游层级 | 最终单段连贯总提示词 + 质量结论 | Prompt 整合 agent / 总控层 |
| 只有角色 / 场景 / 道具 / 参考素材的混合任务 | 总控层 | 缺失信息梳理、分镜骨架、资产库、Prompt 整合、质量 gate | 不可跳过缺失信息梳理 | 完整生产包 | 对应资产 agent / 总控层 |

## 标准流程

### 1. 总控层识别输入并拆任务
- 判断输入类型和当前产物层级
- 输入是剧本：先交给分镜 agent
- 输入是现成分镜表 / storyboard / shot list：先交给字段规范化流程
- 输入是已有 Prompt：先判断它是镜头级、结构化草稿（内部整理态）还是最终态
- 明确核心角色、核心场景、核心道具、核心反转与开场建立方式
- 明确各子 agent 的输入输出边界

### 2. 分镜 agent 生成或规范化分镜
- 负责镜头拆分
- 负责时长、节奏、转场与反转位置
- 输出供其他子模块复用的镜头骨架

### 3. 角色 / 场景 / 道具 agent 并行建立资产库
- 角色资产 agent 建立角色锚点、漂移禁令与参考图引用
- 场景资产 agent 建立空间稳定项、灯光、陈设和氛围
- 道具资产 agent 建立道具识别点、材质与连续性说明

### 4. Prompt 整合 agent 生成镜头级 Prompt 和 segment 级最终视频 Prompt
- 先镜头级
- 再生成结构化的 segment 草稿
- 最后把结构化 segment 草稿压缩成**单段连贯总提示词**
- 保证最终 Prompt 只保留生视频真正需要的信息
- 保证核心角色、核心场景、核心主道具引用不过满
- 不把最终交付写成分栏说明书或重复拆块描述

### 5. 质量 gate 审核
- 结构一致性检查
- 生成稳定性检查
- 开场吸引力 / 开场成立性检查
- 镜头吸引力检查
- 节奏检查
- 脚本改编质量检查
- 成片质感检查
- 安全 / 版权风险检查

### 6. 回退修订
- 质量不过，回退到对应模块修订
- 不允许跳过质量 gate 直接交付
- 回退必须带上问题项、责任模块、修订目标和复检标准

### 7. 汇总交付
最终项目至少保留：
- `storyboard.csv`
- `characters.csv`
- `scenes.csv`
- `props.csv`
- `prompt-package.md`

## 异常场景处理

### 只有一句概念
- 先由总控层补最小项目定义
- 再建立镜头骨架
- 不擅自发明超出用户目标的新世界观

### 只有已有 Prompt
- 先判定它属于镜头级、结构化草稿（内部整理态）还是最终交付态
- 若缺分镜或资产支撑，先补齐骨架再压缩最终 Prompt

### 只有参考图
- 先识别参考图锁定的是角色、场景、道具还是动作
- 先补分镜最小骨架，再让资产类 agent 与 Prompt agent 工作

### 参考图与剧本冲突
- 总控层必须先指出冲突项
- 明确以哪个输入为主
- 未判定主从前，不得直接整合最终 Prompt

### 用户需求超过 15s
- 优先切成多个 `5-15s` segment
- 每段只承担一个清晰推进目标
- 不为了少分段而硬塞过满信息

### 资产太多导致引用过满
- 保核心角色
- 保核心场景
- 保核心主道具
- 删除次级道具、重复风格词和对视频模型无帮助的说明块

## 补全原则

允许补全：
- 镜头语言
- 光影氛围
- 节奏控制
- 一致性约束
- 避免事项

不要补全：
- 新剧情
- 新角色关系
- 与原文无关的世界观扩写

## 失败回路

当任一环节发现问题时，按以下闭环执行：
1. 发现问题并命名问题项
2. 定位责任模块
3. 输出修订目标
4. 明确复检标准
5. 回退到对应模块修订
6. 复检通过后再进入下游
7. 未复检通过，不得进入最终交付

## 质量不过时的回退规则

- 开场吸引力不足或开场建立无效：回退分镜 agent
- 角色漂移风险高：回退角色资产 agent / Prompt 整合 agent
- 场景或道具不稳定：回退对应资产 agent
- 最终 Prompt 过满、不连贯或说明书感过强：回退 Prompt 整合 agent
- 脚本改编不顺：回退总控层重新分配镜头节奏
- 存在安全或版权风险：回退 Prompt 整合 agent / 总控层

## 最终检查顺序

1. 检查输入类型与当前产物层级是否判定正确
2. 检查分镜字段是否完整
3. 检查资产库是否可回溯
4. 检查参考素材是否命名稳定
5. 检查镜头级 Prompt 是否结构完整
6. 检查最终视频 Prompt 是否已合成为 `segment`
7. 检查最终 Prompt 是否为单段连贯总提示词
8. 检查最终 Prompt 是否加入字幕 / 水印限制
9. 检查质量 gate 是否已执行并记录结论
10. 检查不通过项是否附带返工单
