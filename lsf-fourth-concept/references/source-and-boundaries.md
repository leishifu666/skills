# 来源与阅读记录

## 选书

- 书名：*The Field Guide to Human-Centered Design*。
- 作者：IDEO.org。
- 版本：2015 年第一版，192 页，ISBN 978-0-9914063-1-9。
- 中文名在本交付中译为《以人为中心的设计实地指南》，不据此宣称存在对应正式中译版。
- [IDEO.org 官方书目及免费 PDF 入口](https://www.designkit.org/resources/1.html)。
- [IDEO 官方出版介绍](https://www.ideo.com/journal/design-kit-the-human-centered-design-toolkit)。
- [本次实际读取的联合国 UNOSD 托管 PDF](https://unosd.un.org/sites/default/files/ideo_field_guide_to_human-centered_design.pdf)。

选择理由：它把构思、概念筛选和原型检验放在同一个工作过程中，适合解决“第一想法过早成为定稿”的问题；提供正文，能核查方法而不是只依靠书评。它并不论证前三版必差、第四版必好。

## 方法出处与改编边界

以下是方法索引和简短释义，不是章节翻译。

| 书中位置 | 对本技能有用的方法依据 |
|---|---|
| p. 25；pp. 126–127 | 通过反馈继续修订 |
| pp. 31–33；pp. 85–87 | 问题界定应容纳不同解法 |
| pp. 94–95 | 构思期间延后评判，增加可选想法 |
| pp. 97–98；p. 108 | 组合部件，形成完整概念 |
| p. 104 | 借用其他情境中的有用特性 |
| pp. 105–110 | 用设计原则和现实约束检查方案 |
| p. 111；pp. 113、118–119 | 围绕需要学习的问题制作原型 |
| p. 84 | 最初的直觉也可以被探索和检验 |

**特别边界：**书中的 p. 84 不要求抛弃最初直觉，p. 97 允许保留并组合已有想法的有效部分。因此，不能用这本书为“前三个方案客观上都不好”背书。
