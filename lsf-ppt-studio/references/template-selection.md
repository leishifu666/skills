# 模板与主题风格选择

在用户尚未确定视觉方向时读取。目标是先让用户看见全部现有能力，再决定是否需要创建新风格，而不是从零发明。

## 一、Guizang 原生母版

Guizang 只有两套原生 HTML 母版。主题色是母版内的预设变体，不要把九个主题色误称为九套不同模板。

### A · 电子杂志 × 电子墨水

- 原生文件：`assets/template.html`
- 视觉语言：衬线大标题、非衬线正文、等宽元数据、流体或等高线背景、杂志式图文节奏。
- 适合：人文、生活方式、行业观察、文化、艺术、纪实照片和需要叙事感的分享。
- 美学锚点：Monocle 杂志贴上代码。

可选主题：

| 编号 | 主题 | 特征 | 适合 |
|---|---|---|---|
| A1 | 墨水经典 | 墨黑 + 暖米白 | 通用、商业、第一次使用 |
| A2 | 靛蓝瓷 | 深靛蓝 + 瓷白 | 科技、研究、深度内容 |
| A3 | 森林墨 | 深森林绿 + 象牙 | 自然、文化、非虚构 |
| A4 | 牛皮纸 | 深棕 + 暖米 | 怀旧、人文、文学 |
| A5 | 沙丘 | 炭灰 + 沙色 | 艺术、设计、时尚 |

### B · 瑞士国际主义

- 原生文件：`assets/template-swiss.html`
- 视觉语言：12 列网格、全程无衬线、极致字号对比、直角纯色、Hairline 分割线、点阵与单一高饱和锚点色。
- 适合：AI、科技、工程、设计、参数说明、规则拆解、数据与系统型内容。
- 美学锚点：Massimo Vignelli + Helvetica Forever。

可选主题：

| 编号 | 主题 | 特征 | 适合 |
|---|---|---|---|
| B1 | 克莱因蓝 IKB | 白、黑、IKB 蓝 | 通用、AI、科技、设计；默认推荐 |
| B2 | 柠檬黄 | 白、黑、柠檬黄 | 年轻、消费、活力、Y2K |
| B3 | 柠檬绿 | 白、黑、荧光绿 | 未来、新兴科技、Z 世代 |
| B4 | 安全橙 | 白、黑、安全橙 | 工业、警示、决策、强重点 |

一份 deck 只能选择一套母版和一个主题色。原生电子杂志与 Swiss 不得混用；Swiss 的多个锚点色也不得混用。

## 二、LSF 主题风格库

读取 `sources.json` 的 `style_factory.skill_root`，再读取该目录下 `styles/index.json`。这个 JSON 是主题风格库的唯一事实源。

展示规则：

1. 筛选 `styles` 中 `source: leishifu` 的项目，按索引顺序编号为 `L1...Ln`。
2. 每项展示 `displayName`、`category` 和最有辨识度的 3–5 个 `tags`。
3. 必须展示全部现有项目；不得用“等”“更多”或只列推荐项省略。
4. 不把 `source: guizang` 的两项重复列入本节，因为它们已在上一节按母版与主题色完整展示。
5. 某项文件缺失时仍可显示名称，但标注“资产待修复”，不得假装可直接使用。

## 三、创建新风格入口

在现有资产之后固定提供：

`C · 创建新风格`：从截图、HTML、URL、文字描述、色板、已有风格混搭或 CSS/Token 创建新的16维主题，并归档到 LSF 风格库。

只有用户选择 C 或明确拒绝所有现有资产时，才进入新风格提取流程。

## 四、默认展示方式

用户只说“先让我选”“给我模板”“有哪些风格”时，在聊天中依次列出 Guizang A/B、LSF 风格库 L1...Ln，以及 C 创建新风格，并给出一个基于内容的推荐。不要自动生成 HTML、截图或六方案选择器。

只有用户明确要求“做一个可视化选择页”“把模板效果做出来给我点选”时，才使用 `lsf-vibe-ui-selector`。该选择页应优先展示真实内置模板，不得先用自创风格替换它们。

## 五、画布比例

Guizang 两套原生 HTML 模板及其 Presenter 运行时以 16:9 横向演示为基准。

当用户要求 3:4、4:5、9:16 等社交媒体竖版时，必须说明并提供两种路径：

1. **原生演示稿**：保持 16:9，完整使用 Guizang 模板、翻页运行时和 Presenter。
2. **竖版视觉适配**：沿用用户选择的母版视觉语言，重新规划为静态或竖向页面组；保留字体、网格、颜色、直角/圆角、留白和组件纪律，但不直接复制原生 16:9 页面结构，也不声称保留完整 Presenter。

用户明确用于小红书、Instagram 或其他竖版图文时，推荐第二条；仍然必须先从 A/B、L1...Ln 中选择视觉资产，或明确选择 C。

## 六、推荐规则

- 生活方式、人物照片、杂志叙事：优先 A。
- 规则、Prompt、参数、流程、系统说明：优先 B。
- Prompt 展示 + 小红书 3:4：优先推荐 `B1 瑞士国际主义 · 克莱因蓝` 的竖版视觉适配。
- 想要 Swiss 但更偏建筑、编辑和冷峻作品集：推荐 `L9 建筑极简`。
- 想要明显更强的社交媒体冲击：根据内容推荐 `L1 蓝红编辑时尚`、`L5 设计师作品集` 或 `L7 极繁孟菲斯音乐节`。
- 用户明确要求冷白、纸张、衬线和 Editorial：推荐 `A2 靛蓝瓷` 或 `A5 沙丘`，但先说明它们属于电子杂志母版。
