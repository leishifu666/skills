# 图像与品牌素材规范

适用于新建或修改 PPT 中的 Logo、图标、截图、照片、图表和示意图。此文件是 LSF 本地默认规范；用户当前明确要求优先。它覆盖 Guizang 或风格工厂中与原图保真冲突的裁切、比例、滤镜及铺满默认值，不修改上游源码。

## 选什么素材

| 目的 | 素材 | 使用要求 |
|---|---|---|
| 识别公司、平台或产品 | 对应官方 Logo，优先 SVG 或清晰透明 PNG | 从官方站点、品牌资源或用户提供文件取得；配可读名称，不把产品与母公司标志混用 |
| 表达流程和功能 | 模板已有的通用图标，如 Lucide | 风格一致，配必要标签；不拿通用图标冒充品牌 Logo |
| 支持规则、产品能力或案例结论 | 实际官方页面或产品截图、原始图表 | 核验页面，保留相关标题、作者身份、日期和限定条件；图注或备注写明来源及访问日期 |
| 解释场景与概念 | 相关照片、流程图或生成式示意图 | 图片与本页结论有关；生成图注明示意，不能充当真实现场或实验结果 |

比较多个平台时，可用“官方 Logo + 名称 + 能力差异”帮助识别。规则页优先用实际原文截图配解释。没有合适素材时保留清楚的文字或表格，不为装饰增加图片数量。

找不到可核实的官方 Logo 时使用文字名称，不凭记忆重画，不调用图片生成伪造。品牌标志的颜色、字形和留白遵循官方素材，不能仅为统一配色而擅自变色。Logo 出现在对比页不表示合作或背书。

## 保留原图

- 原图纵横比和内容完整性是默认约束；只允许不改变比例的显示缩放，不把“缩小显示”与“压缩图像文件”混为一谈。
- 不覆盖原始文件，不默认有损重编码、降低分辨率、截图后再截屏或转成低质量 JPEG。用户有明确文件体积限制时，先用去重等不损伤画质的方法，再按已获授权的要求生成派生版本并保留原件。
- 未取得裁切授权时，不用 `object-fit: cover`、背景 `cover`、非等比拉伸或容器溢出隐藏来遮掉图片内容。已经获准的裁切按范围执行，不再次询问；“好看”“铺满”“保持网格整齐”本身不等于裁切授权。
- 图片比例与版式不合时，使用 `contain`、留白、调整图文宽度、换版式或拆页。不要为了保留全图而把文字缩到无法辨认。
- 长截图不适合投屏时，可改用来源链接和文字提要，或重新拍摄有标题和上下文的局部页面截图，标明截图范围；不静默裁改原件，也不删除影响结论的限定条件。
- 不用生成式工具重建证据截图上的文字、数字或界面。需要示意重绘时，明确标注示意，并保留真实证据与来源。

## 落位与导出

在项目的逐页计划或素材表记录：页码、用途、原始文件、来源 URL、访问日期、像素尺寸或 SVG viewBox、原始比例、显示方式。沿用已有素材清单格式，不强制重复建立多个文件。素材保存在项目 `images/`；有派生文件时保留原件和处理说明，不写入技能或上游源码目录。

HTML 中可以沿用模板的标准外框尺寸，内部图片默认等比完整显示：

```css
.asset-frame {
  display: flex;
  align-items: center;
  justify-content: center;
  min-width: 0;
  min-height: 0;
}
.asset-frame img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: contain;
  object-position: center;
}
```

外框须在实际版式中有明确可用尺寸；如果使用自然高度，采用 `width: 100%; height: auto`。原图无需被改成与容器相同的比例。

PPTX 也使用等比适配，不调用自动裁切铺满。设原图宽高为 `w, h`，目标框为 `W, H`，取 `s = min(W/w, H/h)`，显示尺寸为 `s*w, s*h`，并在框内居中。导出时检查嵌入图像、截图文字和矢量标志，避免整页光栅化或导出器自动降质造成不可读。

## 验收

- 逐张核对原始宽高比与实际显示；Logo 未拉伸，截图和图表关键内容完整。
- 逐页检查素材用途与来源；官方原文截图不能配超出原文范围的结论。
- 在实际演示尺寸查看文字、图表和 Logo；原图分辨率不足时换高分辨率来源、缩小显示区域或改布局，不把模糊放大当作高清。
- 检查观众视图、演讲者预览以及实际交付的 PPTX/PDF；导出比例一致，图片不与页脚、图注或其他内容互相遮挡。
- 单独注明未能核验的素材或未能运行的导出检查，不能把文字规则更新称为已验证整套 PPT。
