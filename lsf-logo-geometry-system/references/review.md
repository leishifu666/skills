# 逐版对比验收

有参考图的规整、保真、简化修订都执行本页。每次改变成品轮廓、布尔关系、变换或字形后，用最新导出重新检查。只改制图样式时核对成品路径未变，再检查制图对应与排版。批量任务逐款检查。

## 先建立结构基线

制作前保存参考及其来源，划清图形、字标、背景和辅助线。记录不可丢失的识别特征与位置、部件层次、穿插顺序、孔洞和开放通道，并列出允许调整的部位。这些是验收依据，不能做完成稿后再按结果回填。

几何规整可修正曲率、直边、圆角和间距，但仍要保留这些结构。只有用户要求重设计，才以新的目标改变识别结构。探索板选中的格子是该方案的参考。

## 每版必须查看的证据

1. **纯净成品**：先独立看实际渲染，检查主题、重心和轮廓；辅助圆和解释不能掩盖造型问题。
2. **同尺度对照**：原图与成稿排除背景装饰和辅助线，图形与文字分别比较。允许整体等比缩放和平移，记录裁切、尺度和配准；不非等比拉伸、逐部件移动或局部变形来提高重合率。
3. **叠加差异**：查看原图保留、删去、新增或移动的区域。对可靠的单色轮廓测量面积 IoU、双向边界平均/P95/最大偏差、组件和孔洞；记录阈值、归一化 D、样本量及输入哈希。只有数字没有看差异图，不算检查。
4. **关键局部**：放大识别特征、误差最大的区域、S 形转折、弧—线/弧—弧接缝和窄通道。对用户圈出的部位，使用原图、旧版、新版相同范围的裁切，检查实际导出边界。
5. **构造与使用**：确认成品和制图同源，圆/直线确实生成了对应边界；核对相切、间隙、透明反白、开放通道和应用尺寸。

草图排线或背景不能可靠分割时，仍完成视觉对照和局部检查，说明具体哪部分没有数值测量。不能拿排线算准确率。没有参考图的新设计，以用户目标、元素对应和上一版草案检查，不虚构“原图”。

## 数值与结构如何判定

IoU 是黑色区域交并比，不是“Logo 准确率”；双向距离衡量最近轮廓偏差，不能解释识别含义。报告平均、P95和最大值，避免只用平均值掩盖花心或尖端的偏差。折算原图像素时注明原图图形尺寸。

保真任务按约定容差判断；规整任务按允许调整范围和结构基线判断，不设所有图形通用的 IoU 合格线。偏差集中在关键部位时，必须逐处回看。规则化的改动可以降低像素重合，但不能丢掉识别结构。

部件数、孔洞数相同也可能是不同的 Logo，需核对部件的位置、连接、穿插与层次。数量变化定位到具体部位，判断是否符合任务目标；不修改期望值来让检测通过。缩小后通道闭塞仍算使用问题，不能因主尺寸组件数一致就放过。

**以下情况返回修改，重新检查，不能交付为成稿：**

- 主识别特征消失，或改成另一种通用图形。
- 无依据地强加等大旋转、镜像或同心结构，改变层次与负形。
- 接缝折断、误用弧段扫向、短边被圆角挤掉，或切割后出现非预期尖角。
- 构造图只剩比例线，或圆与直线对不上实际边界。
- 重要孔洞、开放通道、部件穿插被删去或粘连。

设计判断、几何残差、源图差异和使用尺寸分别记录。脚本退出码、纯矢量导出或圆数减少，都不能单独作为整体合格的结论。

## 可复用对比工具

先将当前 SVG 实际渲染为图形 PNG，或指定裁切范围排除字标；不要用构造图作为成稿输入。

```text
python scripts/review_rebuild.py reference.png symbol.png --original-crop 44 27 261 235 --out review-v2
```

裁切参数为输入像素的 left top right bottom，右/下边不包含。脚本只用等比缩放与包围盒中心对齐；不旋转、不做局部配准。分割后用最近邻映射到统一坐标，输出 `comparison.png`、`difference.png`、两个配准图及 `review.json`。原图视觉细节仍需与原文件核对。

原图与成稿分别可选亮度或 Alpha 分割，默认亮度阈值 128。白色透明标志使用对应的 `--original-mask alpha` 或 `--rebuilt-mask alpha`。`--max-points` 控制距离采样，`sampled=true` 时最大偏差是采样估计；需要完整边界测量时提高上限至不少于边界点数。详见 [命令契约](tool-contract.md)。

工具只生成证据；`visual_review_required` 始终为 true，退出 0 仅表示所设数值检查没有触发失败。执行者必须打开最新对照和差异图，逐项核对结构基线，记录具体结论后才交付。修改后另存一版检查目录，防止引用旧图或旧报告。
