# 原始 L Logo 案例

本文件仅保存这套工作流的首次真实案例，便于理解节奏与成片效果。不要把其中的 L Logo、图片编号映射或网站 UI 规则套到新用户身上。

配套示例：

- `assets/examples/l-logo-generated-master-5s.mp4`：5.042 秒生成母版。
- `assets/examples/l-logo-web-delivery-3.2s.mp4`：3.208 秒网页加速版。
- `assets/video-references/pacing-reference.mp4`：2.680 秒节奏参考视频。

## 当时提交给 AI 的原始提示词

```text
参考@视频1的整体切换节奏、镜头距离、快速材质切换方式和干净利落的收尾，不复制其中的品牌内容。5秒，黑色纯背景，先锋实验性品牌加载动画。
最开始是纯白色logo@图片15 。

@图片1、@图片2、@图片3、@图片4、@图片5、@图片6、@图片7、@图片8、@图片9、@图片10、@图片11、@图片12、@图片13，全部作为同一个logo@图片15 的造型、结构和材质参考。

始终保持标志的主体轮廓、部件数量、比例、构图位置和朝向一致。标志固定在画面中央，所有参考图片中的材质依次在同一个标志表面流动、覆盖、蜕变和重组，不要将图片并排展示，不要做相册轮播。

0-0.5秒：纯黑画面中出现一道极细的白色轮廓光，迅速勾勒出完整标志。

0.5-4.3秒：镜头缓慢向前推进，标志开始进行高速但丝滑的连续材质蜕变。依次呈现红色透明水晶、黑色蛇皮、蓝色未来玻璃、机械荷花、银紫液态金属、银白玻璃与柔软毛绒、骨骼雕塑、蓝色长绒毛、绿色植物绒毛、银绿色充气金属、原木年轮、彩色纸张拼贴、蓝白发光字符等视觉材质。

每次变化都从标志内部自然生长并沿着结构向外蔓延，前一种材质溶解后无缝过渡到下一种材质。使用流体融化、粒子重组、表面生长、光线扫描和遮挡闪切完成转场。变化节奏逐渐加快，局部可以出现极短的数字故障闪烁，但标志轮廓始终清楚稳定。

4.3-5秒：所有材质高速闪回一次，最终凝聚成@图片14 标志。标志中心爆发一次短促白光，快速缩小并熄灭，画面回到完全纯黑，方便衔接网站首页。

整体质感：高端设计工作室片头、数字艺术、未来材质实验、电影级灯光、精致高光、深邃纯黑背景、强烈材质反差、节奏紧凑、转场丝滑。

镜头要求：主体始终居中，只允许非常轻微的推进与环绕；第一帧和最后一帧均为纯黑；不要大幅旋转，不要改变标志结构。

禁止：图片拼贴式轮播、分屏、相册效果、额外物体、人物、可读文字、字幕、水印、背景场景、标志变形、部件增减、轮廓崩坏、镜头剧烈抖动、低清晰度。
```

新用户应使用 `logo-preproduction.md` 与 `video-generation.md` 的通用流程，而不是直接复用上面的旧编号。
