# LSF Remotion 应用架构

可以使用 Remotion 构建应用：从带有渲染按钮的简单表单，到完整的视频编辑器都可以。

## 选择模板或框架

可以克隆多个 SaaS 模板，或将其作为参考。
如何选择模板或框架，见[框架选择](framework.md)。

## Player 组件

此组件可将 Remotion 预览嵌入 React 应用。Player 的详细说明见[Player](player.md)。

## 渲染

Remotion 支持客户端和服务端渲染。如何选择，以及 Lambda、Vercel、Node.js 和 Cloudflare 方案，见[渲染](rendering.md)。

## Vue

Remotion 在 Vue 中的用法见：https://www.remotion.dev/docs/vue.md

## Angular

Remotion 在 Angular 中的用法见：https://www.remotion.dev/docs/angular.md

## Svelte

Remotion 在 Svelte 中的用法见：https://www.remotion.dev/docs/svelte.md
