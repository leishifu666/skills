# LSF Remotion 框架选择

Remotion 可以与任意 React 框架配合使用。

可用模板如下：

- Next.js：https://github.com/remotion-dev/template-next-app-dir-tailwind。默认使用 Lambda 渲染。
- Vercel Sandbox 渲染：https://github.com/remotion-dev/template-vercel。默认使用 Vercel 渲染。
- React Router 7：https://github.com/remotion-dev/template-react-router。默认使用 Lambda 渲染。
- Express.js 渲染服务器：packages/template-render-server。默认使用 Node.js 渲染。源码见：https://github.com/remotion-dev/template-render-server

可以直接克隆这些模板，也可以将它们作为参考。

现有应用的安装方式见：https://www.remotion.dev/docs/brownfield-installation.md
