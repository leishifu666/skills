# 连续社交媒体卡片模式 · social-cards

把文章、教程或作品过程拆成连续竖版图文，可沿用已确认封面。适用于小红书教程图、设计分享套图与系列社交卡片。共享约束按主 `SKILL.md`；本模式不要求每页三画幅，也不把内页画成九张封面。

## 0. 先确认文章与主标题，再确认平台、比例和风格

生图前明确以下内容，规则按主 `SKILL.md` 的制作前确认执行：

- 使用哪篇文章、哪个版本：文件/链接及内容；多篇、多稿时先确定，不只凭历史标题猜。
- 本组主标题：用于首页的完整文字；文章标题不自动等于首页标题。未定时先读全文给文字候选，用户确认后锁定。
- 平台：例如小红书；已有账号资料不等于选择了这个平台。
- 比例：例如建议 `3:4`，用户明确选择后采用；平台名称不自动决定比例。
- 风格：选择 AI 教程、设计分享、极简作品海报，或明确沿用用户选定封面/参考图。
- 页数：指定数量直接采用，否则根据内容提出建议并等待选择。

已有本次明确选择不重复问，缺项合并补问；可以继续阅读、素材整理和文字候选，但缺任一项不能生成首页、内页或风格试稿。方案记录源文章/版本、主标题、平台、比例、风格、页数和选择依据。

## 1. 读全文，建立内容与素材对应

- 通读全文，查看封面和要使用的案例图，分清主线、步骤、对比、案例、修改过程与交付。
- 记录每页依据的原文段落和真实素材。文章说明多轮修改时保留该过程，不改成一次成功；具体参数只从文章或源文件提取。
- 已为本次明确选择的封面、主图和标题沿用；只确认旧封面的风格时，不自动复制其标题。用户指定的作品总览保持作品数量和识别特征；用户要求选择主图时给候选，不自行更换。
- 原始案例单独保存：构造图、原图、重建图、注册对照、差异图分别标明。组合截图和单张原图不互相冒充。

## 2. 先拆页，再写图中文字

- 页数已确认就按该数量执行。未指定时按内容建议页数并等待选择，完整教程通常可从 6–9 页开始；内容少则减少，内容密则拆页。九页是一个已验证的教程结构，不是每次固定要求。
- 一页解决一个问题或推进一个动作；相邻页按读者需要连起来。首页给主题与成果，内页解释方法，最后给交付或下一步。
- 文章、主标题、平台、比例、风格与页数都已确认后，不逐页重复问是否生成。缺少会影响主张、标题、主图或数量的信息时才补问，继续不依赖答案的整理工作。
- 保存 `制作方案.md` 与 `卡片文案.json`。每页包含页码、标题、正文、原文依据、素材角色、布局和需要的可复制文本；首页使用本次确认的主标题，内页标题按内容提炼。

完整教程的九页结构示例，按主题调整：

| 页 | 内容作用 | 示例展示 |
| --- | --- | --- |
| 01 | 看见成果与主题 | 已选作品总览或结果 |
| 02 | 解释区别或问题 | 有原文依据的工具/方法对比 |
| 03 | 说明如何开始 | 安装、准备素材、入口 |
| 04 | 展开探索步骤 | 可复制调用与选择标准 |
| 05 | 解释关键规则 | 分析结构与操作规则 |
| 06 | 用案例说明 | 真实过程图与结果 |
| 07 | 示范继续修改 | 保留项、修改位置、修改目标 |
| 08 | 示范每轮检查 | 真实原图、重建与差异对照 |
| 09 | 列出交付 | 文件、结果与下一步 |

正文用完整短句写步骤与规则，不只贴标签，也不把正文写成口号。删除装饰性修饰和只为避免质疑的句子。

## 3. 把封面风格转成阅读版式

有已选参考封面时先查看该图，记录背景、字体层级、主题色来源、渐变方向、分隔线、标签和作品区；没有时按用户选定的风格制作。其他平台技能的默认配色不能覆盖用户选择。

- 每页按已确认比例独立生成；可推荐 `3:4` 竖版，未确认不自动采用；目标像素按宿主能力与用户要求写入，实际尺寸以工具文件为准。
- 首页可保留大标题、表情、作者头像与设备；内页缩小标题，扩大正文与证据区。MacBook 只在需要展示整体成果的首页或结束页使用，不每页重复。
- 内页保留色系、粗细字重、标签、分隔线、页码和边距。默认不重复头像署名、不用表情占正文空间；有用户指定时遵从。
- 阅读起点：内页标题约为封面标题的 55%–68%，或不超过画面高度的 14%；根据字数调整。不能为了强行同尺寸把长标题挤成小字。
- 内页正文通常控制在 120–180 个汉字；超过约 220 字或多段代码时优先拆页、压缩说明或把全文另附，不把字体缩到手机看不清。
- 提示词块、参数、链接和文件名用可读的独立区域；关键案例用较大的真实证据区。每页有明确阅读顺序，不把所有元素同时放大。

极简作品海报转卡片时可保留暖白、近黑粗细文字、点线、黑底白字标签、从本次作品取色的单向渐变。具体绿色、表情、Logo、案例和标题只属于本期，不能存成所有卡片的默认内容。

## 4. 处理长提示词和可复制内容

- 图里放得下的提示词逐字写入文案与生图提示词。工具名、Skill 调用、安装地址和参数不改写。
- 原版提示词过长时，卡片注明“压缩调用示例”；完整原文另附 `.txt` 或 `.md`。不能把删节版标成“原版全文”。
- 从已核实的文章或用户文本提取完整原版；拿不到时注明缺失，不根据截图被折叠的部分补造。
- 可复制文本与图中文字同步，分别保存调用、规整、定点修改和检查示例，按主题增减。

## 5. 逐页生成并保留记录

1. 保存每页完整 `prompts/01.prompt.md` 等，写出每一段显示文字、页码、布局、比例、风格与参考图角色，不让工具自行补全文案。
2. 先完成首页，再以验收的首页或已有封面作风格参考。每页显式传入它需要的源图；证据页同时传入各张真实证据，不能只给组合截图让模型猜细节。
3. 每页独立调用图像工具整张生成，记录实际输出路径、提示词路径、引用源图、宽高和字节数。不得把提示词中的目标尺寸当成实际尺寸。
4. 工具只返回近似比例时记录实际比例与差距；不本地裁切、拼图或贴字冒充独立构图。检查缩略图、无损复制与打包可用本地工具。

推荐目录，按本次素材项目调整名称，不写死用户盘符：

```text
<内容项目>/social-cards/
  制作方案.md
  卡片文案.json
  prompts/
  生成记录.json
  成品/                    # 只放本次选定的 N 张图
  检查缩略图/              # 仅用于验收
  原始案例素材/            # 实际对照源图
  可复制提示词.md           # 有操作提示词时附
  基础原版提示词.txt         # 有长原版提示词时附
  卡片预览.md               # 按顺序嵌入成品绝对路径
  <主题>-社交卡片.zip
```

返工版本放在成品目录外，保持原图与旧版可追溯。套图、文案与记录属于同一次内容项目，不另开工作树。

## 6. 每页检查，尤其检查真实对比

- 逐页查看全尺寸图，检查中文、英文名称、Skill 调用、链接、数字、参数、页码和作品数量。
- 查看约 260–360 像素宽的手机缩略图，核对标题层级、段落阅读顺序、正文密度与前后页一致性；密集页再查看原尺寸。
- 证据页并排对照原始素材：原图是否被抹平、重建是否被替换、差异图是否被编造、构造圆和切线是否对应真实构造。不接受“前后都一样”的生成对比图。
- 指标与误差必须有真实计算或原文依据；不能以模型画出的图证明参数、精度或成功率。设计示意图应标明示意，不能冒充真实输出。
- 初次发现错字、缺图、错误证据或结构错误时，只编辑失败页；传入该页与正确源图，逐项写清“保留什么、修改什么”。复查修改位置以及其他文字、配色和素材有没有漂移。
- 明确错误自动纠正一次仍失败时报告未通过项，保留源证据，不把失败页当成成品。用户提出修改时继续完成对应页，不重做整组。

## 7. 整理成品与交付

- 校验成品目录恰好 N 张、页码连续、没有旧版或检查缩略图。检查文件可打开、实际比例/宽高与文件大小一致。
- 生成按页预览，使用宿主支持的本地图片预览和绝对路径，不为了预览发布临时网站。
- 压缩包只收选定的成品、可复制文本和必要源证据；源图与附加文本放子目录，避免被误认为多余卡片。打开 ZIP 检查文件清单、N 张成品与 CRC 完整性。
- 交付成品目录、预览、压缩包、实际尺寸和提示词文本。不得拿目标 1080×1440 描述实际 1086×1448 的文件；这两个比例相同，像素不同。
- 记录本组风格、页数、检查结论和未通过项。保存的是可复用方法，下一组重新分析主题，不机械复制本期主标题、Logo 或作者资料。

## 8. 按请求给发布配套

用户需要时，读已交付的整组内容，提供小红书标题、正文和标签。可调用可用的 `lsf-natural-copy`，它不是制图的前置依赖。

标题贴合内容且有具体结果；正文说明问题、方法、案例和修改经验，不复述九页目录、不夸大“一次成功”。标签围绕真实主题、设计领域与实际工具，不添加无关热点。只请求卡片时不强制追加发布文案；给文案不等于授权上传或发布。
