# LSF 封面与社交卡片

基于 [oil-oil/oil-cover](https://github.com/oil-oil/oil-cover) 二次开发，原作者 [@oil-oil](https://github.com/oil-oil)。保留原版视频封面，增加文章封面、连续卡片、设计风格与本地作者资料。显示名称扩展，调用名仍为 `$lsf-oil-cover`；已有安装、资料和配置继续使用。

## 先判断交付模式

交付模式、视觉风格、工具执行方式分别判断。用户已说明的内容直接采用，不把三者混成一次风格选择。

| 交付模式 | 识别请求 | 推荐交付（须确认） | 按需读取 |
| --- | --- | --- | --- |
| 视频封面 `video-cover` | 视频封面、口播封面、视频三画幅 | 可选独立构图的 `3:4`、`4:3`、`16:9`；按确认的画幅执行 | 自主执行读 `references/agent-native-flow.md`；脚本读 `references/script-mode.md` |
| 文章封面 `article-cover` | 公众号封面、文章头图、博客封面 | 按确认的平台、发布位置与比例制作；可建议 `2.35:1` 宽版 | `references/article-cover.md` |
| 连续社交卡片 `social-cards` | 小红书竖版图文、连续教程图、系列卡片、按封面风格拆文章 | 可建议 `3:4`；文章、主标题、平台、比例、风格和页数确认后执行 | `references/social-cards.md` |

- 用户只要封面，就完成封面；只要卡片，就完成卡片。标题、发布文案和标签按请求补充，制作不构成上传或发布授权。
- 文章与卡片不套视频抽帧流程，不自动生成三画幅。混合请求先列清每项交付，分别执行对应模式。
- 主 `SKILL.md` 规定共享约束；模式参考规定内容和画幅；风格参考规定视觉。卡片内页的阅读规则优先于封面的大标题、设备与署名规则。

## 制作前确认：先内容与主标题，再平台、比例和风格

**三种模式都要在生图前完成确认，包括试稿。** 首先确定本次源内容与主标题，再确认平台、比例和风格。连续卡片须明确采用哪篇文章、哪个版本；文章标题和系列首页主标题分别确认，不能自动当成同一项。

| 确认项 | 如何确定 |
| --- | --- |
| 源内容 | 用户指定的视频/文章/文件/链接及版本；“用这篇文章”且对应唯一文件可直接采用，多篇或多版本不明时补问 |
| 主标题 | 本次封面或系列首页的完整文字；用户指定或选择的原文锁定，未定时先读内容给文字候选 |
| 平台与位置 | 小红书、公众号、B 站等；文章封面同时确定头图、列表图等需要的发布位置 |
| 比例 | 每项实际要制作的画幅；`3:4`、`2.35:1`、视频三画幅等都只是推荐，未经选择不能直接采用 |
| 风格 | 三种模式均让用户选择 AI 教程、设计分享、极简作品海报或明确指定的参考风格；不能替用户选择 |
| 页数（连续卡片） | 使用用户指定数量，未定时结合内容提出建议并等待选择 |

- 本次或同一组任务里已经明确指定、选择、确认的项目直接复用，不重复问；只补缺项，可合并一次询问。历史案例、保存的默认与技能推荐可用作候选，不能代替本次选择。用户明确说“按已选封面风格”或“沿用我保存的默认风格”时，风格已确认。
- “按这张封面的风格”只确认风格，不同时确认旧标题、平台或比例；“小红书教程图”确认平台与任务类型，不自动确认 `3:4`；文章本身的标题不自动成为封面主标题。
- **任一必需项待确认时不调用生图工具，不提前生成首页或内页。** 可以继续读文章、分析视频、整理素材、拆页建议与文字候选；用户未回复不视为确认。
- 在方案中记录已选源内容/版本、主标题、平台/位置、比例、风格与卡片页数，并注明对应用户选择。补图、返工沿用本组确认结果，用户改变某项时只更新受影响部分。

## 风格选择适用于三种模式

采用用户为本次或同组明确选择的风格；未选择时给出以下三种方向或参考图选项，等待选择。提供参考封面但未说明采用其风格时，不能自行认定。用户说“按这个封面的风格”时，先查看该图再提取字体、配色、标签和构图。不因内容提到 AI 自动选择 AI 教程。补图与返工沿用已选风格，历史案例的标题、颜色和表情不成为新一期默认。

| 风格 | 视觉方向 | 需要读取 |
| --- | --- | --- |
| AI 教程 `ai-tutorial` | 真实界面、产品识别、网格与轻透视 | `references/cover-rules.md`；该参考中的视频与头像合成规定只用于视频封面 |
| 设计分享 `design-share` | 标题主次对比、单色渐变、作品展示与作者署名 | `references/lsf-editorial-cover.md` |
| 极简作品海报 `minimal-showcase` | 暖白标题区、细字与特粗关键词、黑底标签、悬浮 MacBook、主题色单向渐变 | `references/minimal-showcase-cover.md` |

只执行所选风格的视觉规范，不混用 AI 教程的大头像安全区、设计分享的 Logo 贴纸与极简作品海报的设备布局。已有封面是本次套图的视觉参考，不能让平台技能的默认色板覆盖它。

## 平台与作者资料

设计分享、极简作品海报以及需要署名的卡片读 [作者资料](references/creator-profiles.md)。

1. 平台须按制作前确认结果使用；未明确时补问，不根据已有账号资料推断。平台与画幅分别记录。
2. 用 `scripts/creator_profiles.py list` 检查资料。已有完整资料直接复用；缺失时收集该平台的准确账号名称与头像图片/路径，只补缺失项。
3. 用户明确允许时才跨平台复用。多平台名称与头像按平台对应，不根据上传顺序猜归属。`@名称` 是显示文案，不推断账号 ID。
4. 用 `set` 将头像归档至本机私有资料目录；默认署名为 `@` 加账号名，自定义署名原样保存。用 `show --platform ...` 读出本次资料，将授权头像作为设计风格的生图参考。
5. 平台资料不同则分别制作并标记平台名。画幅按交付模式确定；连续卡片默认只在首页署名，内页不反复占用阅读空间。

作者资料保持在 `${LSF_OIL_COVER_HOME:-~/.lsf-oil-cover}/`，不改目录、不写进 Skill、Git 或公开示例。公开安装包不含默认用户账号和头像。

## 分析内容、锁定标题与主图

- `SKILL_DIR` 是当前 `SKILL.md` 所在目录。先检查源文件、现有成图、标题、风格、平台和资料。用户选中已有版本后不自行替换；验收过且素材未变的图片可复用。
- 视频：先看首帧，结合字幕或时间线查看 4–8 张候选帧，选择能说明结果或操作的真实画面；片头、旧封面不作主截图。不上传整段视频。
- 文章与卡片：通读全文与相关截图，再提取主张、步骤、案例、修改过程和交付。不只从标题或摘要猜内容；没有证据的操作不标成“实操”“实测”。
- **封面主标题须由用户明确指定或确认后才生图，试稿也一样。** 未确认时先给文字候选，可继续分析和整理素材。“做封面”、风格确认或未回复不等于标题确认。
- **已确认标题锁定文字，只调整断行与层级，不重复询问。** 已确认文章标题被明确用于封面或卡片首页时复用；内页标题按原文提炼，用户指定的内页文字同样保留。用户否定主标题后重新确认。
- 主图由用户选择：已有明确选择或唯一且被指定为主图的素材直接使用；多个不同主图候选时，给编号、缩略图和用途供选择，等待选择期间继续分析与文案工作。不能擅自替换已选的右侧作品图。
- 先查看所有参考图，再明确各图角色：风格、主图、作者、构造证据、原图、重建、差异。需要产品 Logo 时读 [资产清单](references/product-assets.md)，用户自己的 Logo 优先使用其文件；承载工具不自动变成联合品牌。
- 文字只推进内容：写清步骤、规则、结果与修改点。删除不增加信息的修饰和防御性句子，不编造指标、效果或一次成功的过程。

## 表情与风格延续

- 封面需要表情时，根据本期标题情绪与实际结论选择，在方案写明具体表情与理由，不固定套用上一期。疑问、探索可用思考类，成果展示可用惊喜类；强度贴合内容。
- 极简作品海报封面默认一个表情，用户指定无表情时移除。同一主题的多个封面保持表情一致，位置随构图调整。
- 连续卡片内页默认不使用表情装饰，不要求每页重复 MacBook、超大封面标题或头像。保留字体层级、色系、标签和页码，使内容连续且能阅读。

## 工具执行方式

- `script` 与 `agent-native` 是工具方式。视频封面沿用当前明确选择或 `${OIL_COVER_CONFIG:-~/.oil-cover/config.json}` 的偏好；未设置时按原版方式选择并合并保存，不覆盖其他字段。
- 原版脚本用于 AI 教程视频封面。设计风格、文章封面与连续卡片使用支持参考图的宿主内置图像工具，在 Codex 中用 `image_gen`，不需要额外 Key。
- 已明确指定或保存脚本方式时，说明这次目标尚不受脚本支持，取得本次使用自主方式的选择后继续，不改全局偏好。配置与凭据管理仍见 [脚本入口](references/script-mode.md)、[凭据入口](references/api-key-setup.md)。
- 生图参数以宿主当前工具声明为准；工具不可用时说明缺失能力，不自行启用收费 API 或替代模型。分析或修改技能的任务不自行生图。

## 生成、检查与修改

1. 生图前检查制作确认项齐全，再保存方案、逐幅完整 `.prompt.md` 与参考图角色。封面写明锁定标题、逐词字体与字重、表情、构图、色源和署名；卡片写明页码、逐字文案、案例来源与和相邻页的关系。
2. 按已确认比例，每张卡片独立生成。先完成已选风格的首页，再继续内页；修改用图像编辑工具传入待修改图和需要的真实素材，保留已确认部分。
3. 默认不本地贴字、贴 Logo、拼截图或裁图凑构图；原版 AI 教程视频的授权头像合成沿原流程处理。可用本地工具做尺寸检查、检查缩略图、无损复制与压缩包，不把检查图当成成品。
4. **逐幅查看全图，并按手机缩略图检查。** 核对文字、工具名、链接、参数、页码、署名、比例、视觉层级与所选主图。设备页再检查 MacBook、屏幕透视、单向渐变和作品识别。
5. **真实证据要对照源图检查。** 原图、重建和差异不能被模型画成同一张图；不美化原图或发明辅助圆、误差图、数据来支持结论。存在差异时只返工失败页，使用正确源图；无法保真时不把生成示意图当真实对照交付。
6. 明确错误可逐幅自动纠正一次，并复查改动与保留项；仍有问题就报告具体未通过项。用户明确要求的后续修改继续执行，不因单页失败重做整套，不因审美偏好推翻已选版本。
7. 保留原版与修改版，当前交付目录只放选定版本。未通过页不混入成品包，也不声称整套验收通过。

## 保存与交付

- 在原始素材项目或用户指定目录保存，遵循宿主输出约定。视频使用原版视频旁目录；文章与卡片使用本次内容的工作目录，不用跨项目全局临时目录。
- 保存方案、完整提示词、实际工具返回记录、最终图与必要源证据。记录实际宽高、字节数、参考素材和逐幅检查结果，不伪造返回字段、不把近似比例称为精确尺寸。
- 连续卡片附有序预览、成品目录和压缩包；长提示词另附可复制文本。完整原文与压缩示例分别标注。详见 [卡片流程](references/social-cards.md)。
- 交付说明图片位置、实际尺寸、提示词和必要未通过项。用户要求发布配套时，再给贴合内容的标题、正文和标签；不因此登录平台、上传或发布。

## 原版兼容与许可

保留原版脚本、凭据读取、产品参考资产、私有资料路径与 `$lsf-oil-cover`。新增模式不要求迁移账号或重新填写 Key。继承 [MIT](LICENSE)，原作者与第三方素材说明见 [NOTICE](NOTICE)。

## 局部修改

用户反馈字号、留白或局部排版时，只改对应问题，保留已确认的风格、字体、配色、透视与素材。保存修改前图片和提示词；未要求换风格时不重写整套视觉规则。品牌标识与副标题为已确认主标题让位，不追加新主标题。
