# 标题与正文结构

## 标题原则

标题的任务是让人知道内容是什么，同时提供一个真实、具体、可搜索的钩子。参考小红书常见的关键词串联格式，不要写成设计论文标题。

轻量内容不必同时承担审美价值、方法价值和客户识别。优先使用用户原话中的对象、关系和动作。

### 轻量标题

常用结构：

- `[真实来源] + [做了什么]`
- `[具体对象] + [具体动作]`
- `[时间/状态] + [作品类型]`
- `[真实反差] + [作品类型]`

示例：

```text
朋友送的 TRAE 玩偶，被我拿来练手了
拿旧杂志做了一张拼贴海报
今天随手做的动态练习
十字绣质感，怎么放进摇滚海报里｜巡演海报设计
原创海报｜紫色摇滚海报｜手工颗粒感视觉
```

### 标准标题

当内容确实有明确视觉选择时，可以增加一个具体关系：

```text
把未来感玩偶做成一尊古典雕像
给这张海报加了一点古希腊元素
静态海报做完，又试了一个动态版本
```

### 教程、观点与案例标题

```text
3步做完｜[结果]
为什么我会把[对象]处理成[具体方向]
[项目类型]视觉复盘｜[真实问题或取舍]
```

可以使用，但要控制强度：

- “谁把……放进……了？”
- “原来……也能做成……”
- “这张我最喜欢的是……”

这些钩子必须对应画面中真实存在的对象关系，不能编造故事或夸张结果。

避免：

- 为普通练习制造宏大概念或世界观。
- 堆叠“高级、震撼、氛围感、视觉盛宴”等空词。
- 为了显得专业而罗列软件、模型和参数。
- 标题承诺正文没有提供的教程、提示词或结果。

## 正文原则

### 默认：机制优先，句式不固定

作品分享正文追求冷、短、抽象、意外但顺口。笑点可以来自画面，也可以来自语言结构；不要求先铺垫、再反转，更不要求每次在最后一句落梗。

按素材选择一种机制即可：

- **视觉反差**：毛绒身体配金属尖角。
- **错位选择**：把不相干的事物并列成严肃命题。
- **无效回答**：提出问题后撤回、拖延或拒绝选择。
- **荒谬分工**：花负责开，羊负责不配合。
- **突然跑题**：从作品轻轻拐到一种日常处境。
- **认真废话**：句子逻辑完整，但结论故意没解决问题。
- **轻拟人**：给对象一点态度、边界或工作状态。

语感可以是：

- **边界感**：可以可爱，别随便靠近。
- **职责分工**：花负责装可爱，它负责保持距离。
- **一本正经地荒诞**：长得软乎乎，防御系统倒是拉满。
- **轻抽象判断**：今天的温柔，带刺营业。
- **无效回答**：在哲学和外卖之间，我选择再想想。

不要连续复用示例。每次根据画面、用户原话和当下语境重新找落点。幽默不必完全来自视觉反差，但不能借机虚构作者经历、制作事故、客户反馈或事实结果。

### 原话优先

用户已经给出自然表达时，保留核心词汇和克制度，只调整重复、语序和分段。

例如用户说“效果看着还可以”，不要自动改成：

- “效果意外惊艳。”
- “瞬间让整个画面活了起来。”
- “完成了一次从静态到动态的视觉延展。”

### 信息增量

每句话至少提供一项：

- 图片中看不到的新事实。
- 用户明确表达的动机、选择或感受。
- 对具体视觉关系的准确说明。
- 教程或案例中必要的步骤与背景。

没有信息增量的句子删除。尤其检查：

- 重复说明“这是练习”。
- 重复说明“做完了”。
- 机械表示“发出来记录”。
- 无依据地表示“越做越上头、没想到效果很好”。
- 固定互动“大家觉得怎么样”。
- 用户没有说过的作者反应，如“有点奇妙、意外很搭、越做越上头”。

正文可以停在最后一个有效事实处，不强制结尾。

### 视觉描述

风格词必须由具体对象支撑。

较弱：

> 黑底配荧光绿，做了一版科技感海报。

更具体：

> 给机器人加了雕塑感的垂坠服饰和柱式基座，再混进像素与花草。

第二句让读者看到作品内部的关系，而不只是听到一个通用标签。

### 节奏

- 默认轻口语。
- 每段 1 至 3 句。
- 一句只承载一个主要动作或判断。
- Emoji 只在用户风格需要时使用，不作为默认装饰。
- 不为了“完整”补开头、总结或互动。
- 幽默句可以在标题、中间或结尾；需要停顿时再单独成行。
- 一篇保留一个主要笑点；不要层层加梗，也不要解释笑点。

## 按模式写作

### 随手记录

```text
[作品或来源的事实]
[做了什么]
[一个真实选择、工具或结果，可选]
```

### 作品展示

```text
[作品是什么]
[最有辨识度的对象关系]
[一个真实取舍或动态延展]
```

### 教程

```text
[结果]

1. [真实步骤]
2. [真实步骤]
3. [真实步骤]
```

步骤数量服从真实流程，不强制三步。

### 商业案例

```text
[真实项目背景与问题]
[视觉方向]
[关键取舍]
[应用或交付]
[商业引导，仅在用户需要时]
```

## 商业表达

商业表达是条件模块，不是每篇内容的默认落点。

仅在用户明确要获客，或素材确实属于商业案例时使用。表达应建立在真实能力和应用场景上，不承诺未经证实的效果。

可以写：

- “这套方向最后适配到了开屏和线下大屏。”
- “类似的视觉可以继续延展到活动主视觉和社媒物料。”

不要写：

- “需要设计请私信我。”
- “承接所有设计业务。”
- “保证提升销量或转化。”

## Hashtag

按需提供 3 至 8 个高相关标签：

- 内容大类：`#海报设计 #视觉设计 #平面设计`
- 真实风格：`#拼贴设计 #复古未来主义`
- 真实方法或工具：`#动态海报 #AI设计`
- 商业场景：仅在内容确实涉及对应场景时添加。

不为了凑数量添加无关热门词。
